# ゆくすいえ　YUKUSUIE: 16 unbuilt futures

**16回目の、マイホームへ。**

> 遊べるURL：https://yukusuie.zaiya.workers.dev
> デモ動画（3分）：（アップ後に記入）

このプロジェクトは、初めて家を建てる共働きの夫婦の「一度しか試せない家づくり」を、建てる前に16回試せる体験に変える、ブラウザのシミュレーションゲームです。

夫婦は、思いや理想を、ことばや写真、URLで自由に伝えます。架空の住宅会社4社の担当者とヒアリングや打ち合わせを進め、4つの分かれ道で選びます。選ばなかった道も15の世界としてAIが同時に進め、1年後に16区画を見比べます。最後に「悩んだら何を優先するか」「先に伝えておきたいこと」をまとめたレポートを受け取り、本物の打ち合わせに持っていけます。

Built with Claude: Japan 2026 の提出作品です。

## 遊び方
1. 家族を選び、分譲地の区画が当たる
2. 1社目の来場者アンケートを書き、担当者のヒアリングを受ける。帰ってから、伝え忘れたことを担当者に送る
3. 4社の提案と見積を受け取る（見積の「見せ方」は会社ごとに違う）
4. 家づくりの手順に沿って進み、4つの分かれ道で選ぶ。2択のほかに、自分の言葉で答えてもよい
5. 迷ったら「SNSを見る」「自分のAIに聞く」（1ターンに1回）
6. コーディネート、電気の打ち合わせ、契約、着工、引渡し
7. 1年後、16区画を見比べ、選ばれなかった世界線を再生し、担当者それぞれの事情を知る
8. 「わが家の、ちょうどいいバランス」のレポートを受け取る

家づくりの手順：見学・相談 → 初回打ち合わせ → プラン提案・見積 → 設計申込・詳細打ち合わせ → ショールーム → 契約 → コーディネート・電気 → 申請・着工 → 上棟 → 施主検査 → 引渡し → 1年後


## Claudeの使い方
- **言葉はClaude、数字はコード。** 金額・日数・面積・判定は、すべて計算エンジン（`src/engine/`）が出します。Claudeは数字を作りません
- 自由な答えは、Claudeが「変更の提案」に読み替え、tool use でエンジンに問い合わせて検算してから、条件つきで受け止めます。画面の「いま起きたこと」の帯は、この実際の呼び出しの記録です
- 役割ごとにモデルを使い分けています（自由回答の読み替え・入口の写真とことばの読み取り・レポート／担当者／施主のスマホの中の「自分のAI」と、15の世界の一言）。分かれ道の2択は、計算エンジンが持つ固定の選択肢です
- 決断の理由を記憶し、1年後のレポートで「あのとき守ろうとしたもの」として言葉にします。「失敗でした」とは判定しません

## 技術構成
- Cloudflare Workers（画面の配信とAPI）、KV（プレイの記録、回数と費用の上限）
- Anthropic API（APIキーはWorkers側に置き、ブラウザには出しません）
- 画面は素のJavaScript。家と分譲地は画像生成を使わず、座標からコードで描いています（SVG／Canvas、動画素材の一部は three.js）

## 開発について
- 開発期間（2026-11-02〜）に、Claude（claude.ai）とClaude Codeだけで作りました。実装と作業はすべてClaudeが行い、外部のコードや素材は取り込んでいません
- 企画・予行演習・見せ方の試作（`prototypes/`、`design/`）は claude.ai で、実装は Claude Code で行いました。作業の記録は `docs/devlog.md` と `docs/devlog/` にあります
- 担当者の人格・ヒアリングの話題・情報収集・SNS・電気・レポートの言い回しの素材は、期間中に claude.ai で新しく作りました（`data/content/`）。事前の調査メモそのものは含めていません

## 動かし方（開発）
- `npm install` → `npm test`（計算エンジンの検算）
- `npm run dev`（ローカル。`.dev.vars` に `AI_MODE=mock` を置くと、Claudeを呼ばずに代わりの処理で動く）
- `node scripts/playthrough.cjs [URL]`：通しの自動プレイ（スクショを `out/shots/` に保存）
- `node scripts/api_smoke.mjs URL`：Claude APIの疎通確認（役割ごとに1回だけ呼ぶ）
- `?replay=再生コード`：実際のプレイの記録を再生（Claudeは呼ばない）。`?rec=1` で撮影用に操作の表示を消す

## フォルダ
- `src/`：ゲーム本体（Worker、画面、エンジン）
- `prompts/`：役割ごとのシステムプロンプト（版番号つき）
- `data/`：期間中に作ったデータ（JSON）
- `design/`：画面と動画の見本（版の変遷）
- `prototypes/`：期間の初めに作った見せ方の試作
- `video/`：動画素材の書き出し
- `docs/`：設計、開発記録
