# ゆくすいえ　YUKUSUIE: 16 unbuilt futures

**16回目の、マイホームへ。**

Claudeと描く、家づくりの16の未来。現役の建築士が、Claudeとつくった家づくりシミュレーションです。

- 遊べるURL：https://yukusuie.zaiya.workers.dev （ログイン不要。公開は 2026-11-11 23:59 まで）
- デモ動画（3分）：https://www.youtube.com/watch?v=3GdKBZA1ehI

## 概要
はじめて家を建てる人の「建てたあとにしかわからない経験に、建てる前は触れられない」という課題を、建てる前に16回建ててみる体験に変える、ブラウザのゲームです。

家は「3回建てないと満足できない」と言われますが、土地と建物で、およそ5,007万円、年収の7.5年分（出典：住宅金融支援機構「2024年度 フラット35利用者調査」（土地付注文住宅））。ほとんどの家族にとって、家づくりは一生に1回です。住まいづくりの経験知は、専門家や経験者のもとにたくさんあるのに、はじめての施主には、断片的にしか届きません。SNS や AI で情報を集めても、「映える家」や「誰かの正解」が、ときには少し息苦しい。理想の住まいが、他人の切り貼りで埋め尽くされないように、なにかできないか。そこから考えたのが、家づくりの未来シミュレーターです。

プレイヤーは、会社ごとに人柄の違う Claude の担当者と打ち合わせを重ね、4つの分かれ道で選びます。選ぶたびに、選ばなかった道も別の世界として同時に進み（2×2×2×2＝16）、1年後に16の家を見比べます。建てる前に、16回建ててみる体験です。金額や日数は計算エンジンが出し、言葉は Claude が担います。

住宅会社を訪ねる前に、ふたりで一度通しておき、最後に受け取る「ふたりが大切にしたいこと」の1枚を、本物の打ち合わせに持っていけます。

## 遊び方
家づくりの手順にそって進みます（見学・相談 → 初回打ち合わせ → プラン提案・見積 → 契約 → 色決め・電気 → 着工 → 上棟 → 施主検査 → 引渡し → 1年後）。

1. **はじめる**：あなたは夫か妻か、ひとりで遊ぶ（パートナーは Claude が演じる）か、ふたりで交互に遊ぶかを選ぶ。家族の条件と、分譲地の区画を確かめる
2. **情報収集**：架空の住宅会社4社のチラシに順位をつけ、SNS の投稿を見て、訪ねる2社を選ぶ
3. **アンケートと打ち合わせ**：来場者アンケートに答え、2社の担当者と初回の打ち合わせ。帰り道に、伝え忘れたことをパートナーと話す
4. **提案の日**：2社の案（間取りの骨組み・立体・見積）を見比べる。見積の「見せ方」は会社ごとに違う
5. **4つの分かれ道**：だれと建てる？／なにを優先する？／いくらまでかける？／どう仕上げる？　2択のほかに、自分の言葉で答えてもよい。迷ったら「SNSを見る」「自分のAIに聞く」
6. **色決め・電気**：外壁や床を決め、電気の図面を確かめる（伝えたはずの要望が入っているか）
7. **着工・引渡し**：工事の早送りと、鍵の受け取り
8. **1年後**：16区画を見比べ、世界樹で選ばなかった世界線をたどる
9. **レポート**：「わが家の、ちょうどいいバランス」を受け取る（印刷用は A4・4ページ）

## 仕組み
役割の違う複数の Claude と計算エンジンで、16の世界を同時に計算します。判断は Claude、記憶と数字はコードが受け持ちます。
- **言葉は Claude、数字はコード。** 金額・日数・面積・判定は、すべて計算エンジン（`src/engine/engine.js`）が出します。Claude の文に数字が入っていたら、コードが差し戻します。担当者が金額を話すときは「総額」などの枠で書き、表示の直前にエンジンの値を入れます
- **役割ごとにモデルを使い分け**：上位のモデルは設計担当（間取りの骨組みを、エンジンを道具として呼びながら組む）。中位のモデルは担当者・パートナー・自由な答えの読み替え・レポート。軽量のモデルは「自分のAI」と、選ばなかった15の世界の担当者のひとこと（詳しくは `docs/TECH_FACTS.md`）
- **自由な答えの読み替えと検算**：2択の外の答えは、Claude が「変更の提案」に読み替え、tool use でエンジンに問い合わせて金額・ローン・工期・建蔽率を確かめてから、条件つきで受け止めます
- **担当者の研修（Claude 同士）**：客役の Claude と会話させ、審査役の Claude が採点し、直しては、また回す。担当者の話し方を、この研修で鍛えました。計496回の会話・せりふだけで約55万字。人間が演じたら、会話だけで約30時間、担当者役・お客さま役・審査役で延べ約100時間分（話す速さ1分300字ほかで概算。仮定は `docs/TECH_FACTS.md` の6-6）。決まり文句に逃げた発言は 92 から一桁に、審査役の「頼まれたことに答えたか」（5点満点）の平均は 1.69 から 2.67 に（`docs/REP_TRAINING_LOG.md`、生の記録は `data/training/runs/`）
- **出来事の記録と再生**：1回のプレイは、選択と Claude の入力・出力・プロンプトの版まで、出来事としてすべて記録します。`?replay=再生コード` で同じ流れを何度でも再生できます（再生では Claude を呼びません）
- 決断の理由を記憶し、1年後のレポートで「あのとき守ろうとしたもの」として言葉にします。「失敗でした」とは判定しません

## 間取りと絵について
- 間取りは、作り手が期間中に言葉にした決まり（LDK は南、玄関は東か東南、水回りは北 など）から組む、簡易的なゾーニング図です。実務の図面や、勤務先を含む住宅会社のノウハウは持ち込んでいません。金額や延床とは連動しない、見せ方のための絵です（`src/web/zoning.js`、`docs/LAYOUT_RULES_v1.md`）
- 家や区画の絵は、設計の初めに作る白い検討模型のように、あえて抽象的にしています。比べることが目的だからです。絵は画像生成を使わず、座標からコードで描いています

## 開発について
作り手（建築士）は、コードが読めません。代わりに、Claude でチームを組みました。進め方は、建築設計と同じ、分担によるチームプレイです。
- **Claude（チャット、claude.ai）**：構想と設計、指示書を書く司令塔、辛口のレビュー
- **わたし（作り手）**：指示と報告を受け渡す、決める・捨てる、演出を加える（あえて自動化しない）
- **Claude Code（実装）**：ゲーム本体、監査
- **Claude Code（動画）**：録画・書き出し・字幕。編集ソフトは使わず、コードで
- 点検も Claude に。Claude 自身に必要なスキルを指示して作らせ（`.claude/skills/` の4つ：守り、攻め、初めての人、一貫性）、実装していない Claude（サブエージェント）に監査とレビューをさせました
- claude.ai のクラウドの環境で作業したので、Claude のアプリ（Mac・スマホ）から、育児のあいだにも作業を進められました
- 設計と指示の文書は、動画の制作時点で57本・約22万字。提出後の main では、期間中のコミット 127件、文書 69本・約27万字（数え方は `docs/TECH_FACTS.md` の6）
- 文書の入口は `docs/README.md`。開発記録は `docs/devlog.md` です

## これから
家づくりは、判断の連続です。ざっくりでも全体を知っていれば、少し心にゆとりができます。16回建てて見えてくるのは、正解ではなく、ふたりが大切にしたいことです。

今回、入れられなかったことも、たくさんあります。作り手の個性、プロセスの多様さ、感覚的な心地よさ。家の作り手は、住宅会社だけではありません。設計事務所、建築家、大工さんもいます。次は「だれと建てる？」の相手ごとに、進め方が変わるようにしたいと考えています。ことばにならない感動は、現実で、大切な誰かと探してみてください。

専門家・経験者と、はじめての施主。そのあいだをつなぐ、問いかけの AI を目指しています。

## 公開について
- 1つのIPあたりの回数の制限と、費用の上限があります。上限に達すると、AI の応答は決まった代わりの文になります
- API キーはサーバー（Cloudflare Workers）の側だけに置き、ブラウザには出しません
- 再生コードを知っている人は、そのプレイの記録を見られます。写真は保存しません

## 技術構成と動作に必要な環境
- 遊ぶ：パソコンのブラウザ（横長の画面を推奨）。ログイン不要
- Cloudflare Workers（画面の配信と API）、KV（プレイの記録、回数の上限）、Durable Objects（費用の計量、スマホ連携）
- Claude API（構造化出力・tool use）。画面はフレームワークを使わない素の JavaScript。描画は SVG／Canvas
- 開発に必要なもの：Node.js、Wrangler、Cloudflare のアカウント、Anthropic の API キー（Workers の秘密として登録）

## 動かし方（開発）
- `npm install` → `npm test`（計算エンジンと間取りの絵の検査）
- `npm run dev`：ローカルで動かす（`.dev.vars` に `AI_MODE=mock` を置くと、Claude を呼ばずに代わりの処理で動く）
- `npm run deploy`：Cloudflare Workers に公開（API キーは `wrangler secret put ANTHROPIC_API_KEY`）
- `node scripts/playthrough.cjs [URL]`：通しの自動プレイ（スクショを `out/shots/` に保存）
- `node scripts/rec_replay.cjs <再生コード> [速さ]`：記録を再生モードで録画
- `?replay=再生コード&rec=1`：撮影用に、操作の表示を消して再生

## フォルダ
- `src/`：ゲーム本体（`worker.js` サーバー、`engine/` 計算エンジン、`web/` 画面・描画・印刷レポート）
- `prompts/`：役割ごとのシステムプロンプト（版番号つき）
- `data/`：期間中に作ったデータ（`content/` 担当者・アンケート・チラシ・SNS など、`training/` 担当者の研修）
- `test/`：検査
- `scripts/`・`tools/`：自動の通し、録画、研修、組み立ての道具
- `.claude/skills/`：自作のスキル
- `video/`：動画の場面と書き出しの道具、字幕
- `design/`：画面と動画の見本（版の変遷）
- `prototypes/`：期間の初めに claude.ai で作った見せ方の試作
- `app/`：初期の試作の版（いまのゲーム本体ではない）
- `docs/`：設計・指示・記録（入口は `docs/README.md`）
