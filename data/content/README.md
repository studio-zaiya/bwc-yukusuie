# data/content　中身の素材集（content-v1）

期間中（2026-11-04）にClaude（claude.ai）で作成。Claude Code の実装で、そのまま読み込んで使う。数字は入れていない（金額は `"engine"` と書いた場所をエンジンが計算する）。

| ファイル | 中身 | 使う画面 |
|---|---|---|
| `personas.json` | 4社の担当者（半分は女性）とコーディネーター2人（男女）。口調の見本、深く聞く話題／聞き漏らしやすい話題、得意な助言、言いがちな一言、1年後に明かす「それぞれの事情」、表情のヒント | ヒアリング、見積の見比べ、打ち合わせ全般（担当者のシステムプロンプトの素材）、1年後の「それぞれの事情」、P4-a（コーディネーターは男女をランダム） |
| `hearing_topics.json` | ヒアリングの話題11。担当者の質問例2つ、夫婦の答えの例、見落としの種（種がまかれる工程と芽が出る工程） | 1社目・2社目のヒアリング、見落としの台帳、電気の打ち合わせ、1年後 |
| `info_sources.json` | 情報収集の入口6つ（展示場・見学会・知人・SNS・比較記事・チラシ）×4社×2つの、偏った断片情報（良い話と気になる話） | 見学・相談のステップ（訪ねる2社を選ぶ前） |
| `sns_posts.json` | 架空のSNS「ひろば」の投稿60件。話題、立場、相矛盾する組（contra）、隣の世界由来の印（neighbor） | 「SNSを見る」のポップアップ（いまの話題で3〜5件、立場を混ぜて出す） |
| `ai_assistant.json` | 「自分のAI」のロール設定（システムプロンプトの素案、出力の長さ、略図を返す条件）と、電気の打ち合わせ用の固定のおすすめ6つ | 「自分のAIに聞く」のポップアップ |
| `electrical.json` | 会社ごとの電気の標準仕様、契約に入れてあるオプションの例、要望の候補タグ13、契約外だったときの返事の型（伝えていたのに漏れた／伝えていない） | P4-b 電気の打ち合わせ |
| `report_phrases.json` | レポートのタイトル候補30、世界線の呼び名30、教訓20（それぞれ選択の組み合わせのタグ付き）と、文字数・禁止語の確認ルール | レポート（画面版・印刷版）、1年後の16区画のカード。Claudeの生成が確認に通らないときの代わり |

## 使い方の注意
- 禁止の言い回しは含めていない。`report_phrases.json` の `checks.bannedWords` は確認用の一覧（画面には出さない）
- 担当者の名前と性別は仮。変える場合は、`personas.json` と画面のアバターをそろえる
- 「自分のAI」は、数字を出さない・1回だけ・最後はプロへの確認に軽く誘導、を守る
- どの会社も貶めない温度で書いている。書き足すときも同じ温度で
