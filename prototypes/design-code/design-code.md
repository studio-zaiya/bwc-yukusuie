# デザインコード v0.1　「16軒目の、わが家」

アプリと3分動画で共通に使う決まりです。見本は同じフォルダの specimen.html にあります。

決勝では、事前に収録した動画を再生して審査員が議論します。なので判断の基準は次の3つです。
- 再生された1コマで伝わること
- 説明なしで読めること
- 審査員に「作り物だ」「雑だ」と思わせないこと

方向は「バシッと明るく、家づくりが楽しい」です。暗い場面は、1年後の冬の夜の1回だけにします。

## 1. 色

### 1-1. 基調（昼の分譲地）

| 役割 | トークン | 値 | 使いどころ |
| --- | --- | --- | --- |
| 紙 | `--paper` | #FFFAF0 | UIの地、カード、札 |
| 空 | `--sky` | #CFEBFA | 俯瞰・山場の背景の上側 |
| 地面 | `--ground` | #F3E7CF | 敷地、方眼紙 |
| 芝 | `--grass` | #9BD27A | 庭、区画のふち |
| 墨 | `--ink` | #1E2B36 | 文字、線、数字。真っ黒は使わない |
| 墨（弱） | `--ink-2` | #6B6358 | 補足の文字 |
| 夜 | `--night` | #1B2440 | 1年後の夜の場面だけ |
| 窓の灯り | `--lamp` | #FFD98A | 夜の窓、完成した家 |

### 1-2. 夫婦の2色と、第3の答え

| 役割 | 面の色 | 文字に使う色 | 形での区別（必須） |
| --- | --- | --- | --- |
| かず | #E8701F（橙） | #B3541A | 実線、節は ■（四角） |
| ゆう | #1C8DCC（空色寄りの青） | #14699A | 実線、節は ●（丸） |
| 第3の答え（ふたりで出した答え） | #F2C230（金） | #8C6A00 | **太い破線**、節は ◆（ひし形） |

- ゆうの色は、試作で多かった「青緑」をやめて、空色寄りの青にしました。色覚の型を変えて試算すると、橙と青なら、どの型でも色差が十分に残ります（ΔE 95〜114）。
- 金と橙は、2型の色覚では近く見えます（ΔE 20）。そのため**第3の答えは、色ではなく破線と ◆ で区別するのが決まり**です。色はあくまで補助にします。
- 枝の色の割合で「ふたりのバランス」を見せるときは、凡例にも ■ ● ◆ を必ず添えます。

### 1-3. 住宅会社 A〜D

- **どの会社にも、強調色を割り当てない。** 4社とも、墨の札に白抜きの文字（A／B／C／D）だけにします。正解の色に見える会社をつくらないためです。
- 4社の違いは、札の形で区別します（A＝四角、B＝三角、C＝丸、D＝六角）。色の明るさも4社で同じにします。
- 社名は「Aハウス」「B工務店」「Cデザイン」「Dホーム」のようにアルファベットで表記します。ロゴのような装飾はつけません。

### 1-4. 家の状態

状態は**色だけでなく、形で区別**します。悲劇を強い色で煽ることもしません。

| 状態 | 見せ方 |
| --- | --- |
| 完成 | その世界の仕上げの色（外壁・屋根）。夜は窓に灯りがともる |
| 工事中 | 白い模型（白い面に墨の輪郭）と、灰色の足場 |
| 工事中止 | 更地の土の色（#D9CDB4）に灰色の仮囲い。札は「工事中止」。赤は使わない |
| 空き家 | 仕上げの色を6割ほど淡くする。窓は暗いまま |
| 未着工 | 地面と地縄（細い墨の破線）だけ |

### 1-5. 札の色

| 札 | 地 | 文字 | 縁 |
| --- | --- | --- | --- |
| 統計 | #2E5A88（紺） | 白 | なし |
| 現場の実感 | 紙 #FFFAF0 | #5A4A3C（こげ茶） | こげ茶の破線 |
| 数字の札（区画の上に浮かぶもの） | 紙 | 墨 | 墨の細線、影は弱く |

- **増額や減額は、良い・悪いの色で塗らない。** 符号（＋／−）と矢印だけで示します。赤や緑の点滅もしません。

### 1-6. コントラスト比（計算値）

WCAGの基準は、本文が4.5以上、大きな文字が3以上です。

| 組み合わせ | 比 | 判定 |
| --- | --- | --- |
| 墨 / 紙 | 13.9 | 本文可 |
| 墨 / 空 | 11.6 | 本文可 |
| 墨 / 地面 | 11.8 | 本文可 |
| 墨 / 芝 | 8.2 | 本文可 |
| 墨 / 金 | 8.6 | 本文可（金の札の文字は墨にする） |
| 墨 / 橙 | 4.7 | 本文可（橙の札の文字は墨にする） |
| 白 / 橙 | 3.1 | 大きな文字だけ。**原則使わない** |
| 墨 / 青 | 3.9 | 大きな文字だけ |
| 白 / 青 | 3.7 | 大きな文字だけ。**原則使わない** |
| かずの文字色 #B3541A / 紙 | 4.8 | 本文可 |
| ゆうの文字色 #14699A / 紙 | 5.4 | 本文可 |
| 第3の答えの文字色 #8C6A00 / 紙 | 4.8 | 本文可 |
| 白 / 統計の紺 #2E5A88 | 7.2 | 本文可 |
| こげ茶 #5A4A3C / 紙 | 8.1 | 本文可 |
| 墨（弱） #6B6358 / 紙 | 5.7 | 本文可 |
| 白 / 墨（金額の帯） | 14.4 | 本文可 |

決まり：**橙・青・金の面の上に文字を置くときは、墨の文字にする**。白抜きの文字を置かない。

## 2. 文字

### 2-1. 書体

| 役割 | 第1候補（手元にあるとき） | Web用の代わり（Google Fonts） | 最後の代わり |
| --- | --- | --- | --- |
| 本文・UI・字幕 | ヒラギノ角ゴシック（Hiragino Sans / ProN） | BIZ UDPGothic | Noto Sans JP, sans-serif |
| 見出し・大きな数字 | ヒラギノ丸ゴ ProN | Zen Maru Gothic（700） | 本文と同じ並び |
| 表の中で桁をそろえる数字 | ヒラギノ角ゴシック ＋ 等幅数字 | BIZ UDGothic | monospace |

- BIZ UDPGothic を選んだのは、ユニバーサルデザインの書体で字幕でも読み間違えにくく、漢字の字形も素直だからです。
- **動画は、書き出す機械（Mac）のヒラギノで描きます。** ただし、Web版との見た目のずれが目立つ場面（UIをそのまま映す場面）では、両方を同じ書体にそろえます。
- 書体は、すべて読み込みが終わってから描き始めます（`document.fonts.ready` を待つ）。代わりの書体のまま書き出すことは禁止です。

### 2-2. 文字の大きさ

| 段階 | 動画（1920×1080） | アプリ（基準16px） | 用途 |
| --- | --- | --- | --- |
| 特大の数字 | 160px | 64px | 前振りの「5,007万円」、カウントダウン |
| 題名 | 96px | 40px | 「16軒目の、わが家」 |
| 見出し | 64px | 28px | 場面の問い（「だれと建てる？」） |
| 字幕・本文 | 44px（下限36px） | 16px | 台詞、説明 |
| 札 | 32px | 14px | 数字の札、統計／現場の実感の札 |
| 注記・出典 | 24px（下限） | 12px | 出典、注記の文 |

- 動画では、24pxより小さい文字を出しません。
- 1行は、動画で全角24字、アプリで全角40字までにします。
- 字幕は画面下の安全域（下から8%）の上に置き、2行までにします。

### 2-3. 数字の書き方

- 金額は「万円」が単位です。桁区切りを入れます。例：4,070万円、+380万円、−210万円。
- 1万円未満の端数は出しません（4,070.5万円とは書かない）。月々の返済だけは「月々 12.3万円」のように小数1桁まで許します。
- 増減には必ず符号を付け、マイナスは全角の「−」にします。
- 日数は「あと46日」、期間は「60日」。温度は「14℃」、割合は「39.3%」。
- 数字が並ぶところでは、等幅数字にします（`font-variant-numeric: tabular-nums`）。
- 統計の数字には、すぐ横か下に出典を付けます。画面では短くし、正式な名前は概要文に書きます。

### 2-4. 表示時間（動画）

- 字幕は「文字数÷4」秒、かつ1.8秒以上表示します。映画字幕の「1秒4文字」に合わせた目安です。
- 題名や場面の問いは2.5秒以上。
- 数字の札は、数字が止まってから1.2秒以上動かさずに見せます。
- 1つの画面に、同時に動く文字の塊は1つまでにします。

## 3. 動き

### 3-1. 使う動き

| 動き | 決まり |
| --- | --- |
| 家が育つ | 基礎が置かれる → 壁が下から伸びる（行き過ぎは6%まで）→ 3コマ遅れて屋根がのる → 色が流れ込む |
| 線が描き進む | 線の太さは一定。角の手前で少し減速する。古い線は明るさ35%まで落とす |
| 数字が回る | 0.6〜0.9秒で止まる。最後は減速して止める |
| 白から色へ | 白い模型に、仕上げの色が下から上へ流れ込む（0.5秒） |
| はんこ | 1.12倍から等倍へ、0.12秒。画面は揺らさない |
| カメラ | 平行移動と、寄り・引きだけ。アイソメの角度は回さない |
| 切り替え | 要素でつなぐ（線が次の画面の線になる、など）。無関係な画面どうしのクロスフェードは使わない |

### 3-2. 使わない動き

衝撃波の輪、粒子の爆発、ネオンの光、レンズフレア、画面の揺れ、RGBのずれ、跳ねすぎる動き（行き過ぎ10%超）、回転して現れる文字、遅すぎる1文字ずつの打ち込み、無限に回り続ける読み込み表示、紙吹雪。

### 3-3. 速さとイージング

| 種類 | 長さ | イージング |
| --- | --- | --- |
| ボタンの反応 | 0.12〜0.15秒 | `cubic-bezier(0.22, 1, 0.36, 1)` |
| UIの出入り | 0.25秒 | 同上 |
| 登場（家、札、カード） | 0.4〜0.6秒 | 同上 |
| 移動（カメラ、線の描き進み） | 0.6〜0.9秒 | `cubic-bezier(0.65, 0, 0.35, 1)` |
| 機械的なもの（速報帯、時計） | 一定速度 | `linear` |

- 1カットで伝えることは1つ。動きの主役も1つにします。
- 動画は30fpsで、描画は時刻 t の関数で決めます。アプリでは `prefers-reduced-motion` のとき、動きを0.01秒に縮めます。

## 4. 画面の部品

| 部品 | 決まり |
| --- | --- |
| 数字の札 | 紙の地、墨の細線、角丸4px。1枚に数字は1つ、言葉は12字まで。区画の真上に浮かべ、細い引き出し線で家とつなぐ |
| 統計／現場の実感の札 | 数字の右肩に小さく付ける。「統計」は紺の地に白、「現場の実感」はこげ茶の破線の縁 |
| 2択カード＋自由入力 | カード2枚は同じ大きさ、同じ形、同じ色（夫婦の色では塗らない）。それぞれに「この答えの本物の魅力」を1行で書く。下に「ほかの考え」の入力欄を常に置き、横に配偶者かアシスタントの一言（例：「両方じゃない答えも、ありかも」）を添える |
| カウントダウン | 「土地の契約期限まで　あと46日」。数字は特大、言葉は札の大きさ。残り日数に応じて帯が縮む。色で煽らない。14日を切ったら帯の端に ! の印を付ける |
| 金額の帯 | 画面下に常に出す。墨の地に白の文字で「総額 4,070万円　借入 4,760万円　月々 13.2万円」。変わった数字は回して止め、直前の値との差（+60万円）を0.9秒だけ添える |
| 住宅会社の札 | 1-3の決まりどおり。担当者の名前は札の下に小さく |
| 注記 | 本作の注記の文は、ゲームの最初と動画の最後に全文で出す。プレイ中は画面右下に「設定は簡略化しています」とだけ常に小さく（12px）置き、押すと全文が開く |
| 出典 | 動画では数字の下に24pxで。正式な出典の一覧は概要文とREADMEに書く |

## 5. 審査員にノイズや落胆を与えないためのチェックリスト

書き出しの前に、毎回すべて確認します。

**文字**
- [ ] 代わりの書体や豆腐（□）がない。書体の読み込みを待ってから描いている
- [ ] 文字がはみ出していない、重なっていない、2行の字幕が3行になっていない
- [ ] 字幕と札が、表示時間の決まり（2-4）を守っている
- [ ] 句読点、括弧、長音、全角・半角が統一されている（数字と単位は「4,070万円」の形）

**言葉**
- [ ] 用語がぶれていない。人物は「かず」「ゆう」（ひらがな）、会社は「Aハウス」「B工務店」「Cデザイン」「Dホーム」、画面は「俯瞰」「世界樹」、答えは「第3の答え」、分かれ道は「だれと建てる？／なにを優先する？／いくらまでかける？／どう仕上げる？」
- [ ] 実在の会社名・地名・人名、それを連想させる色づかい・ロゴ・言い回しがない
- [ ] ギリシャ文字を使っていない
- [ ] 絵文字を使っていない（記号は ■ ● ◆ ！ ？ に限る）
- [ ] 施主や「後悔した人」を貶める言い方がない
- [ ] 作り手の名前・顔・勤務先が映っていない

**数字**
- [ ] 画面の金額・日数・温度は、エンジンが出した値そのものである（手で打った数字がない）
- [ ] 同じ世界の数字が場面をまたいで矛盾していない（総額 = 前の総額 + 増減）
- [ ] 統計の数字には出典があり、現場の実感の数字には「現場の実感」の札がある
- [ ] 端数や精度が作り物に見えない（4,070.5万円のような出し方をしない）

**動き**
- [ ] 動画に映した操作は、すべてアプリで本当に動く。動かない部分は「構想」と明示している
- [ ] 使わない動き（3-2）が入っていない
- [ ] 1カットに主役の動きが1つだけになっている

**画**
- [ ] 夫婦の色・第3の答えが、形（■ ● ◆、実線と破線）でも区別できる
- [ ] どの住宅会社も、色で正解に見えていない
- [ ] 暗い場面は1年後の夜だけで、それ以外は明るい
- [ ] 注記の文が、最初と最後に出ている
