# 案C「1本の線が描き進む一筆書き」

## 2行の要約
明るい方眼の紙の上を、色のある1本の線が描き進み、3軒の家→上がる折れ線→省エネのバッジと同じ形の家の列→マンションとリフォーム→スマホと付箋でふくらむ家→ふたつの吹き出しと時計→無数の点→作り手と施主をつなぐ波、とつながっていく（44秒）。
最後に線が4回分かれて16本になり、「2×2×2×2＝16通り」を見せたあと、16本の先が色のついた16軒の家に変わって「それなら、建てる前に、16回建ててみよう。」で終わる。

## 見どころ
- 前の図形の終わりが次の図形の始まりになり、カメラが線の先を追って横に流れる。描き終えた場面の線は薄くなる。
- 線が面に変わるのは最後の1か所だけ（16本の先が、色の違う16軒になる）。
- 数字は線に添えて置き、「統計」（青緑の札）と「現場の実感」（橙の枠の札）で区別。出典は画面の左下に小さく出す。
- 「5,007万円」は数字が回って止まる。時計の針は回り続ける。
- 分岐の線は2色（橙と青緑）。前振りでは夫婦の色とは言わず、本編の夫婦の色分けへの伏線にとどめた。
- 後悔の約4割は扱っていない（くすむ表現なし）。施主の吹き出しは「全部伝えたのに、なぜか違う。」として、施主を下げない言い方にした。

## 弱点
- 線と文字の一筆書きなので、地味に見える場面がある（とくに省エネと「リフォーム／マンション」）。音とテンポで持たせる必要がある。
- 1場面に置ける文字が多めで、約4秒ずつだと読み切れない行がある。本番では行を削るか、場面を5秒ずつにする。
- 民間調査の数字は使っていない（大工の人数も、民間の研究所の推計のため外した）。
- 確認した静止画は、ネットにつながらない環境のため代わりの書体（Noto Sans CJK）で描かれている。ヒラギノや Zen Kaku Gothic New で出すと、字幅が少し変わる。

## 2日の制作の中で作るなら
- 約4〜6時間。このまま整えて動画に書き出すなら4時間（文字の調整、音のきっかけ、書体の確認）。数字をデータファイルから読む形にするなら+1〜2時間。
