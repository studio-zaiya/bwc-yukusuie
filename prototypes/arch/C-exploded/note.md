# 案C「ゆくすいえ のしくみ ― 分解図」 v3（4層・最上段に世界樹と敷地）

## 2行の要約
最初の画面（左に世界樹、右に16の敷地）が斜めに倒れ、4枚の層に分かれる。下から「ふたりの一言（地面）→ Claude（上位・中位・軽量）→ 計算エンジン（コード）→ 世界樹と16の敷地」。記録は左端の背骨。
金の◆が「窓だけトリプルにしたい」から下→上へ通り抜け（読み替える→2択を書く→＋60万円／＋7日（再審査）→世界樹の節）、最上段で金の破線の17本目の枝が伸び、その先に17番目の敷地が現れて家が建つ。「言葉はClaude、数字はコード。」で締める（12.5秒）。

## v2からの変更点
- 層を5枚から4枚に。世界樹と16の敷地を、最上段の1枚にまとめた。
- 最上段は左→右に読む：左に世界樹の根、枝が右へ開き、枝先から細い点線で右側の16の敷地へつながる。最初の正面の画面も、左に世界樹・右に敷地の同じ配置。
- 17本目の金の破線は、世界樹の左下の節から伸び、枝先から敷地の並びの右手前に17番目の敷地を出して、基礎→壁→金の屋根の順に家を建てる。
- 世界樹は最上段にあるので、上の板に隠れなくなった。
- 人物は、層が開ききってから（3.7秒〜）出るようにした（前回の「畳まれた板の横に先に出る一瞬」を解消）。層の中のラベルも、開ききってから出る。
- 記録の背骨は4層に合わせ、刻みは「ふたりの一言／読み替え・2択／＋60万円／＋7日／17本目の枝と家」。

## 弱点
- 最上段に情報が集まり、世界樹・16軒・17本目・17番目の家が1枚に乗るので、手前の左側（17本目の未来のラベル）と計算エンジンの「台帳」の札が近い。
- Claudeと計算エンジンの層は、上の板越しに半透明で見える部分がある。各層の中身は5〜10秒では読み切れず、「流れ」が伝わる前提。
- 斜めの投影なので、最上段の「左→右」は厳密には左上→右下の向きに見える。正面の画面では正確に左→右。
- 確認は代わりの書体（Noto Sans CJK）。ヒラギノでは字幅が少し変わる。

## 制作時間
- 磨くなら2〜3時間（ラベルの間隔、音のきっかけ、正面の画面を実際のアプリの1コマに差し替え）。
- アプリの記録から◆の通り道と背骨の刻みを駆動するなら、さらに1〜2時間。
