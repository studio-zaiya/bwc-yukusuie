# H4「見やすさの演出を足す」― 期限・ズーム・ティッカー

## 2行の要約
前振り案Cの16本の線が左から入り、16区画に降りて地縄になり、基礎→骨組み（上棟）→白い下地・防水シート→仕上げ材の順にカラフルな16軒が建つ（28秒）。
大きなカウントダウン（土地の契約まで→着工から→引き渡しから1年）、世界07へのズームと「2択じゃなくても、いい。」で生まれる17本目、1行ティッカー、一度だけの花びらを足し、最後に「ゆくすいえ／YUKUSUIE: 16 unbuilt futures／もしもの家づくりを、16の世界で、同時に。」。

## 流れ
- 0–3秒：左から入る16本の線（橙と青）が4回分かれ、各区画へ降りて地縄（墨の破線）になる。左上「土地の契約まで あと60日」が減り、14日を切ると「！」
- 3–11秒：基礎→骨組み→白い下地→仕上げ材。カウントダウンは「着工から 0→270日」に替わる。画面下の1行ティッカーに16世界の出来事（基礎ができた／上棟／外構は住んでから／打ち合わせ19回目／工事が止まった）
- 11.4–15.6秒：世界07に寄る。同じ大きさの2択カードの下に、金の破線と◆の入力欄「窓だけ、トリプルガラスにしたい」が打ち込まれ、「2択じゃなくても、いい。」。07から金の破線がのび、盤の外に17区画目の地縄が現れ、「同時に進む世界 16→17」
- 15.6–22秒：引いて「引き渡しから 1年」。春の光、花びらが一度だけ舞う。03は工事が止まった世界だが、花の咲く更地として描く
- 22.4–28秒：ロゴの板（ゆくすいえ／YUKUSUIE: 16 unbuilt futures／補足の一文）

## 変更点（立場5からの）
- 工事の順番を、地縄→基礎と骨組み→白い下地（淡い青灰の防水シート）→仕上げ材に変更。説明ラベルは一切出さない（区画番号だけ）
- 陸屋根は薄い屋根版と立ち上がりだけ。中央の煙突状の部材（光の糸）をなくした。07は陸屋根で南だけ庇
- 仕上げをレンガ調・木目・ガルバ（空色）・塗り壁（白、たまご色、若草、さくら）などに増やし、屋根も5色で明るく
- 夜と窓の灯りの締めをやめ、春の昼で終える（電力会社のCMっぽさを回避）
- 金額は画面に出さない。数字は日数と世界の数だけ（シム系・財務ゲームに見えないように）
- 立場3から「大きな期限」「要所のズーム」「1行ティッカー」「花びら」だけを取り入れ、紙吹雪・集中線・揺れは入れていない
- デザインコードに合わせ、かず橙・ゆう青の線、第3の答えは金の太い破線と◆。住宅会社には色を付けていない
- 舞台は absolute＋translate(-50%,-50%) scale() で中央固定。900×506 と 1920×1136 の両方で中央に収まることを確認

## 弱点
- 07へのズーム中、分かれ道のカードと字幕が家に重なり、07がどの家か一瞬わかりにくい（07の番号札をズーム中も出すと良い）
- 冒頭の16本の線は、前振りCの最後の絵（16本の先が家になる）と形が完全には一致しない。本番では前振りの最終コマの線の位置を受け取って描き始める必要がある
- 1年後のティッカーは文字だけで、家の側に変化（洗濯物、うさぎ）がまだない
- three.js の影はソフトウェア描画だと重い。書き出しは問題ないが、古いPCでの実機再生はかくつく可能性がある
- 確認した静止画は代わりの書体（ネットにつながらない環境のため）

## 制作時間の目安
- このまま磨くなら3〜4時間（07の番号札、前振りの線とのつなぎ、ティッカー文言）
- 世界の状態の記録（エンジン出力）から家の形・仕上げ・ティッカーを流し込む形にするなら、さらに半日
- 音と書き出しに1〜2時間
