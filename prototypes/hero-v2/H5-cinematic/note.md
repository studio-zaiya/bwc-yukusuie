# H5 ゆったりした映画的な山場 ―「4つのカット」

## 2行の要約
- 前振りの16本の線が左から降りてきて、16区画に地縄を張る。家は 地縄→基礎→骨組み→白い下地と防水シート→仕上げ の順に建ち、仕上げ・屋根の形・色がそれぞれ違う。
- 1軒（07）に寄ったあと引くと、各家から線がのぼって空で扇形の世界樹になり、金の破線と◆の17本目が外へ伸びる。花びらと若葉が舞う昼の空で「ゆくすいえ」。28秒。

## カット（1カットに1つの動き）
1. 0〜7.2秒：線が降りて地縄を張る（ゆっくり下降）
2. 7.2〜15.4秒：16軒が建つ（横へ平行に流れる）
3. 15.4〜21秒：07に寄る（寄るだけ）。花びらが舞い始める
4. 21〜28秒：引いて空の世界樹 → ロゴ「ゆくすいえ」「YUKUSUIE: 16 unbuilt futures」「もしもの家づくりを、16の世界で、同時に。」
カットのつなぎは0.25秒だけ紙の色に抜く。画面の文字は最後の3行だけ。

## 05からの変更点
- 札・ログ・数字をすべて外し、文字は最後のロゴだけにした（読み切れない問題への対応）。
- 工事の順番をレビューどおりに。「模型」などのラベルは出さない。
- 陸屋根は薄い屋根版と立ち上がりだけで、中央には何も置かない（煙突問題の解消）。07は白い塗り壁の箱型に南だけ庇。
- 仕上げ8種（塗り壁、木目、ガルバリウム、レンガ調、サイディングなど）× 型5種（切妻、陸屋根、片流れ、平屋寄り、箱型＋庇）。
- 終わりは夜の灯りではなく、昼の空と花びら。
- 03の世界は基礎のあと「はらっぱ」に戻り、黄色と白の小さな花が咲く（工事中止を赤や仮囲いで強調しない）。
- 世界樹は空の扇形。枝はデザインコードの夫婦の2色（橙・青）、第3の答えは金の破線と◆。
- 舞台は position:absolute＋translate(-50%,-50%) scale() で中央に置き、900×506 と 1920×1136 の両方で中央に収まることを確認。

## 弱点
- 3カット目（07に寄る）は、手前の家の屋根が画面の下を少しふさぐ。カメラをもう一段上げるか、手前の区画を低い家にしたい。
- 最初の2秒は線がまだ画面に入っておらず、やや間延びする。前振りの線と色・太さをそろえて、つなぎ目なしに受けたい（前振りCは青緑、ここはデザインコードの青）。
- 家から空の葉へのぼる線が途中で交差する。区画と葉の並びの対応をもう少し整理する余地がある。
- 静止画はネットにつながらない環境で、代わりの書体で確認した。

## 制作時間の目安
- このまま磨くなら3〜4時間（カメラの微調整、前振りとのつなぎ、音のきっかけ）。
- エンジンの世界の記録（仕上げ・型・結末）を読んで描く形にするなら、さらに2〜3時間。
