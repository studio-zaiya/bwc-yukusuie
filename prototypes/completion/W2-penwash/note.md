# W2 ペンと淡彩（建築家の手描きパース風）「竣工の1枚」

## 2行の要約
マイホームが完成した瞬間に、プレイ画面から「建築家が描いた竣工パース」に切り替わる。紙の上に揺らぎのある細いペンで2点透視の家が描かれ、最後に淡い水彩が差され、「16回目の、マイホームへ。」で止まる（約8秒、9秒ループ）。

## 状態から描く仕組み
- ページ先頭の JSON（form／roof／finish／accent／eave／carport／tree／season／timeOfDay／family）だけを読んで、毎回その場で形・線・色を組み立てる。画像は1枚も使っていない
- 3つの状態を用意し、下のボタンで切り替え可能
  - A：総二階・陸屋根・白い塗り壁＋木の縦張り・南だけ庇・カーポート1台・春・昼
  - B：1階が大きい・片流れ・ガルバリウム＋木の縦張り・カーポート2台・秋・夕方
  - C：平屋寄り・切妻・レンガ調・南だけ庇・夏・朝
- 本番では、エンジンの記録（世界の状態）をこのJSONの形で渡せば、その世界の家が描かれる

## 見どころ
- 線：揺らぎ、端のはみ出し、重ね線、消失点へ向かう薄い補助線、陰の面の斜めハッチング。手前の面が奥の線を隠す（描き進むたびに処理）
- 水彩：縁の色だまり、顔料の粒状感、水が戻ったにじみ、光の当たる側の抜け。紙の地に乗算で重ねる
- 描く順番：補助線→外形→屋根と基礎→開口部→仕上げの線→陰→点景（0.4〜4.4秒）、色は空→地面→壁→窓→木→人（4.0〜6.6秒）
- 仕上げは線の描き分けで表す（木の縦張りは細かい縦線、ガルバリウムは間隔の広い縦線、レンガ調は横の目地、塗り壁はほぼ線なし）
- 陸屋根は笠木の薄い帯だけで、中央には何も立てていない。工程名などの説明ラベルは画面に出さない

## 弱点
- 人の点景が棒人形に近く、少し幼い。体の形をもう一段描き込みたい
- 2階の窓や東面の窓の位置は、形の型ごとの決め打ち。間取り（ゾーニング）と連動していない
- Bの「1階が大きい」は、2階の箱の奥行きが1階と同じなので、上から見た形の変化が弱い
- 確認した静止画は、ネットにつながらない環境のため代わりの書体（題字の手書き風の書体が出ていない）
- 1フレームごとに線と面を描き直すので、古いPCでは再生がやや重い可能性がある（動画への書き出しには影響しない）

## 制作時間の目安
- 磨く（点景の人、窓位置のゾーニング連動、Bの形の調整）：3〜4時間
- エンジンの記録からJSONを渡してプレイ画面とつなぐ：1〜2時間

## 確認
- Playwright で 1920×1136 と 900×506 の両方で開き、舞台が中央に収まることを確認。ページのエラー0件（フォントの読み込み失敗のみ）
- 途中で直したこと：窓が壁に塗りつぶされていた前後関係（付属物を壁の奥行きに合わせた）、空と芝の水彩の縁が直線的だった点、木の樹冠が泡のように見えた点、木が画面の端で切れていた点
