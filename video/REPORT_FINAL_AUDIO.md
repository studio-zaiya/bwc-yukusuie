# 音声入りの版（動画担当・11/7）

人間のナレーション（ボイスメモ、1本通し・約184秒）を入れた。

- 自分の声の版：`out/final/yukusuie_final_own_voice.mp4`（1080p）／`_720p.mp4`
- 声を変えた版：`out/final/yukusuie_final_voices.mp4`（1080p）／`_720p.mp4`
- 字幕：`video/subs_v14_voice.srt`（声に合わせた）／場面表：`video/edl.json`

## やったこと
- **位置合わせ**：映像を流しながらの収録と読み、話し始めと字幕の出だしを照らした。録音は映像より約4.7秒遅れて始まっていた（46本中42本で一致）
- **字幕を声に合わせる**【Claude】：声の自然な間を崩さないように、声は動かさず、字幕の切れ目を声のかたまりに合わせた（`video/audio/align_subs.py`）。ほとんどは±0.7秒以内の移動。「ことばにならない感動は…」だけ約2秒後ろへ（声がそこから始まっているため）
- **声の整え**（ffmpeg）：音割れの修復（クリップした83か所）、低い雑音のカット、ノイズ低減、こもりを少し減らし聞き取りの帯域を少し持ち上げ、歯擦音を抑え、軽く圧縮して音量をそろえた
- **BGMとSE**：試聴版より約7dB下げ、声が入っている間は自動でさらに下げる（ダッキング）。全体は −14 LUFS（YouTube の目安）、ピーク −1dB

## 声を変えた版【人間の依頼／配役の細部は Claude】
WORLD（pyworld）で、声の高さ・声道の響き（フォルマント）・息の成分を分けて作り直した（`video/audio/voice_change.py`）。元の声から作っていて、AIの音声合成は使っていない（この環境から音声合成のモデルに届かないため）。

| 部分（字幕） | 声 | 高さ（中央値） |
|---|---|---|
| ゆくすいえとは（1〜12） | お茶目なおじさん：低く太く、抑揚を大きく | 約104Hz → 93Hz |
| プレイ画面（13〜26） | 落ち着いた明るい女性 | 約106Hz → 184Hz |
| 結果とレポート（27〜34） | 若い女性 | 約111Hz → 211Hz |
| 実装について（35〜42） | 別の男性（少し若く明るく） | 約121Hz → 138Hz |
| さいごに（43〜46） | 作者の声のまま【Claudeの提案】 | — |
| 締めのロゴの声（タイトルコール） | 男性・女性・子どもの3声を、0.07秒・0.15秒ずらして重ねる | — |

## 注意
- 動画担当はこの環境で音を耳で聴けない。声の高さは測って確かめたが、自然さ・聞きやすさの判断は人間にお願いしたい
- 女性・子どもの声は、元の声から高さを大きく動かしているので、機械っぽさが残る所があるかもしれない
