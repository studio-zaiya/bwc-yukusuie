# v3 画面の見本 前半（S1〜S5）

- 共通の枠は `screens/_s.js`。L1（`../play/common.js` の window.L）の進捗バー・担当者の実況・選ばれなかった世界線・大きな家をそのまま使う。数字はすべて `app/engine.js`。
- 仮ロゴは `#logo-slot` の文字。ロゴ決定後はこの要素の中身を差し替えるだけ。
- お金の札：会社を決める前（S2・S3）は「住宅会社を決めると表示します」の点線の札。S4は見積金額、S5は「契約金額＋増工金額（契約済み）」に切り替わる。
- S4（?v=ask|done）：分かれ道3の2択の札と自由回答欄。done は「いま起きたこと」の帯（Claudeの読み替え → エンジンの見積 +58万円 → 審査 返済負担率29.8% → 工程 +7日 → 判定 条件付き）。数字は engine.simulate の実値。本番は実際の呼び出しの記録から作る。
- S4は62日目（ローン特約の期限まで28日）に置き、simulate の期限も28日で計算して、時計の札と条件の文をそろえた。
- S5：請負金額は 3,696（05の仕様）＋58（窓）＝3,754万円。借入4,803万円、返済負担率29.8%、月々約14.0万円（変動1.2%）。工期は engine の07の日数から。
