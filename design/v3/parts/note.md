# 場面の部品 v3（人間の11/4 11:17の指示 4) 10) 11) を反映）

作成：Claude。共通：`_shared/v3.css`、`_shared/v3.js`（進捗バーは短い表記、右上に見積金額／借入金額、会社の札、表情の変わるアバター）。自分の家と「選ばれなかった世界線」は v2 の `layout/common.js` を呼び出して描く。

## P1-survey 来場者アンケート（`?co=A|B|C|D`、`?fill` で記入済み）
- 実際の入力欄（input / textarea / radio / checkbox）。Tabで次へ、1行の欄はEnterで次へ、選択肢は矢印キー、Ctrl＋Enterで記入を終えてP1-chatへ
- どの会社か：用紙のヘッダーに大きな会社の札、用紙の様式を会社ごとに変える（A：二重罫の帳票、B：黒帯のかんたんアンケート、C：罫線の自由記述、D：手書きふうのご相談シート）。右に会社名と場所、記入した会社のタブ（記入済み／記入中）
- 2社目以降は「1社目（Aハウス）に書いた内容を写しました。違うところだけ直してください。」と出して、入力を繰り返さない
- 弱点：4社分の用紙の差は罫と形だけなので、引きの絵では似て見える

## P1-chat ヒアリング（`?co=A|B|C|D`、撮影用 `?s=think|talk|smile`）
- L1のレイアウト：上に自分の家（要望から考えた大きさを半透明で）、右にチャット、下に「選ばれなかった世界線」（上下を詰めて190px）
- 担当者の口調はビルダーごとに変える（A：きっちり、B：元気、C：丁寧で寡黙、D：気さく）。本番は中位のClaudeが、担当者の設定と口調の指示から生成する
- チャットの下に「SNSを見る」「自分のAIに聞く」（L1の改訂と同じ置き場所。自分のAIはこの場面で1回まで）
- 「応答の流れを再生」ボタン：考え中（文字が届くまで）→ 話す（文字が流れるあいだ）→ 笑顔（言い終わり）→ 待機

## P1-avatars 4人のアバターと口調の見本
- 線画のSVG。表情は `data-s="idle|think|talk|smile"` を切り替えるだけ。まばたきはCSSのアニメーション、話す口は2コマの切り替え。外部ライブラリなし、画像なし
- 実装：ストリーミングの開始で `think`、最初の文字が届いたら `talk`、完了で `smile`、1.4秒後に `idle`。エラー時は `idle` に戻すだけで壊れない
- `prefers-reduced-motion` ではアニメーションを止める

## P4a コーディネート（`?wall=std|galva|nuri&color=0..2&floor=std|oak|pine&inner=vinyl|eco|nuri`）
- 外壁：窯業系サイディング（標準）／ガルバリウム鋼板／塗り壁。外壁の色は用意したパレット（各3色）から選ぶだけで、家の絵にそのまま映る（生成はしない）
- 床：シート貼りフローリング（標準）／オークの挽き板／無垢のパイン
- 内壁：ビニールクロス（標準）／自然素材クロス／塗り壁。色は選べない
- コーディネーターは増額だけを言う（月々は出さない）。右上の札は「契約金額＋増工」に増工分が足される
- 単価は仮置き。engine.js に「仕上げ」の単価表として追加する必要あり

## P4b 電気の打ち合わせ（`?v=ask|reply`）
- 図は使わず、テキストだけ。左に標準仕様の一覧と「契約に入れてあるオプション」
- 右のチャットで担当者は「左の内容で進めますが、問題ないでしょうか。」とだけ聞く。「この内容でOK」か、追加の要望・指摘を伝える
- 指摘したあと（reply）：「すみません。契約には入っていないんです」と言われ、追加分が左の一覧に金の◆で載り、右上の増工に足される
- 単価（壁掛けテレビの下地と配線 +4.8万円、寝室のLAN +2.5万円）は仮置き
