# L4 推奨：アップ＋ギャラリー＋処理の記録（レビュー2本の取り込み）

- ねらい：L1を土台に、2つを足した。
  1. 家の絵の下に「いま起きたこと」の帯：Claude（読み替え）→エンジン（見積・審査・工程）→判定、をバッジで大きく。本番は実際の呼び出しの記録（tool useのログ）から組む枠で、台本は流さない。試作では engine.simulate の実値（差額・負担率・日数）を表示している。
  2. ギャラリーの「あなたと同じ選択をした世界」を金の破線で囲む：決断の瞬間に、16のうちどの世界が同じ道にいるかが一目でわかる（レビューの「選択で世界が変わる」を、世界を独立に保ったまま正直に見せる）。
- 良い点：「ただのチャット」に見えない。原因（入力）と結果（数字・世界）が同じ画面にある。動画の実機パートをこの1画面で撮れる。
- 弱点：情報が多く、1080pの縮小動画では下段のひとことが読みにくい。処理の帯は直近の1件だけなので、フェーズが進むと古い記録が残る（フェーズ切り替えで畳む等が要る）。
- 実装の手間：中〜大（1日弱）。tool useのログを帯に流す配線が要る。
