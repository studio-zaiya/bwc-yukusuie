# L1 自分の家のアップ＋下にギャラリー

- ねらい：主役は「わが家」。上に07の家を大きく（計画中は白い模型が半透明で濃くなり、着工後は基礎→骨組み→白い下地→仕上げ）、下に15の世界を同じ日付のサムネイルで並べる。各サムネイルに会社の札・いまの工程・ひとこと・進み具合の線。
- 良い点：自分の家にフォーカスしたまま、横目で15の世界の差（Cは打ち合わせが深く遅い、Aは契約が早く先に上棟）が読める。動画で「同時に進む」が一枚で伝わる。担当者の実況は家の絵の下に小さく重なる。
- 弱点：サムネイルが小さく（約120px）、ひとことは1080pでぎりぎり。15個が同時に変わると視線が散る（変化した区画だけ一瞬ふちを光らせる等の工夫が要る）。
- 実装の手間：中（半日）。エンジンの世界状態をそのまま読むだけ。サムネイルの描画はSVGで軽い。
- 操作：右上のボタンでフェーズを進める／再生。`?p=3.4`（設計申込のころ）、`?p=8.4`（上棟のころ）、`?rec`で操作ボタンを隠す。
