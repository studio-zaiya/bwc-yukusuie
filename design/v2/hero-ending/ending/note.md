# 締め3案（Claude案）
共通：明るい昼。E3と同じ温白色の光る線を空に描く。コピーは「16回目の、マイホームへ。」1行だけ（題名の下）。最後に注記（読める約2秒を確保。本編で延長可）。H8の方向で、洗濯物・畑・うさぎ・自転車・道を走る子どもを足した。工事が止まった区画は花の原っぱとベンチ。

## E-A「にぎやかな昼の16区画 → ゆっくり引き → 題名」13秒
- 要約：区画の間を低めに見下ろし、暮らしの小道具と人が動く分譲地から、空に光る線が育つのに合わせて引いていき、題名と注記。
- 見どころ：一番素直。Heroと同じ盤・同じ線なので、冒頭と締めが呼応する。
- 弱点：小道具と人が小さく、引きでは点になる。寄りの最初3秒が勝負。
- 本番化：1.5時間。

## E-B「わが家の庭のアップ → 紙のレポートが手前に → 題名」14秒
- 要約：07の庭（洗濯物、畑、うさぎ、自転車2台、家族4人、1年点検に来た作り手）を寄りで見せ、紙の「わが家のバランス」が手前に来て読める時間だけ止まり、右下へ退くと同時に引き → 題名。
- 見どころ：持ち帰りレポートにつながる。実写の手渡しに切り替えるなら、紙が手前に来る瞬間がつなぎ目になる。
- 弱点：紙の中身（行）は試作の固定文。本番はエンジンのレポート出力から流し込む。紙は2D（DOM）なので立体の盤と質感が違う。
- 本番化：2〜3時間。

## E-C「自転車の子と、うしろに伸びる光の線 → わが家で手を振る → 引き」13秒
- 要約：自転車の子を斜め上から追い、通ったあとに地面へ温白色の光の線が伸びる（世界樹と同じ見た目）。わが家の前で家族が待っていて、引いて題名。
- 弱点（大きい）：道幅が2しかなく、家と屋根でさえぎられる。線が淡い道の上で目立たない。道を広げるか、線を少し浮かせて太くする必要がある。現状は3案で一番弱い。
- 本番化：3〜4時間（道幅の見直しを含む）。
