# P3-a 右に縦長のスマホ（タイムライン）

- ねらい：待ち時間に施主がスマホを見る。タイムラインは一括生成した投稿を傾向つきで流す。隣の世界の投稿（2月の朝がひんやり）が混ざる。
- 良い点：家（敷地）が画面の主役のまま、SNSの誘惑が並ぶ。タブで相談・メッセージに切り替えられる。
- 弱点：投稿の文字が小さい。動画ではスマホに寄る必要。
- 実装の手間：低〜中（投稿はJSONで事前生成）
- 数字：坪単価・ローンの月々はapp/engine.jsから。色決めと電気の単価は _shared/parts.js の COORD に仮置き（engine.jsへ移す予定）
