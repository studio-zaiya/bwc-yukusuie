# P3-b 画面の下に重ねる汎用AIへの相談

- ねらい：下からシートが上がり、くらしのAIと相談。AIは「全部叶います」と答え、図には階段が2か所ある破綻を含む。最後は「設計士さんに確認を」と誘導する。
- 良い点：汎用AIの万能感と危うさを、絵で見せられる。担当者とは別の役のAIだと伝わる。
- 弱点：シートが画面の半分を覆う。破綻に気づかない人も多い（それでよい）。
- 実装の手間：中（破綻を含む案は、ルールで1つだけ混ぜる）
- 数字：坪単価・ローンの月々はapp/engine.jsから。色決めと電気の単価は _shared/parts.js の COORD に仮置き（engine.jsへ移す予定）
