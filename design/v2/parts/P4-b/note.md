# P4-b 電気の打ち合わせ（図面と要望の照合）

- ねらい：電気の図面に、コンセント・スイッチ・照明・エアコン・LANを記号で描く。最初に伝えた要望のうち、図面にないもの（テレビの壁掛け）を金の破線で囲む。赤は使わない。
- 良い点：「事前に伝えたのに反映されていない」が、説明なしで見つかる。追加の費用（1か所1.2万円、LAN2.5万円）はその場で出る。
- 弱点：図面の読み取りに慣れない人にはやや難しい。記号は凡例が要る。
- 実装の手間：中〜高（図面と要望の対応表をデータ化）
- 数字：坪単価・ローンの月々はapp/engine.jsから。色決めと電気の単価は _shared/parts.js の COORD に仮置き（engine.jsへ移す予定）
