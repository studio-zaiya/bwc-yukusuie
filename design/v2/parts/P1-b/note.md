# P1-b チャット主体のヒアリング

- ねらい：アンケートは上の4項目に畳み、チャットが主役。左の敷地に、夫婦の要望が付箋として貼りつき、ボリュームが膨らむ。担当者は「全部できますよ」で早く切り上げる（不十分なヒアリング）。
- 良い点：入力が速い。建蔽率の計算（エンジン）が常に下に出ている。
- 弱点：紙の実感はない。チャットボットに見える危険がいちばん高い。
- 実装の手間：低（v0.1の延長）
- 数字：坪単価・ローンの月々はapp/engine.jsから。色決めと電気の単価は _shared/parts.js の COORD に仮置き（engine.jsへ移す予定）
