# P2-a 伝え忘れをメッセージで送る

- ねらい：帰り道、パートナー（ゆう）に「伝え忘れた？」と聞かれ、架空のメッセージアプリ「ことづて」で担当者に送る。担当者が盲点（室外機の位置）を突き返す。2社目以降は同じ要望を渡した旨のトーストで入力を省く。
- 良い点：スマホという生活の道具で、自由入力が自然に起きる。盲点の返信がClaudeの担当者役の見せ場。
- 弱点：スマホが画面の右3分の1を取る。
- 実装の手間：中（メッセージ画面1つ。盲点の質問はトラブル目録から選ぶ）
- 数字：坪単価・ローンの月々はapp/engine.jsから。色決めと電気の単価は _shared/parts.js の COORD に仮置き（engine.jsへ移す予定）
