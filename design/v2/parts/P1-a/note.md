# P1-a 紙の来場者アンケート

- ねらい：1社目の展示場で、紙のアンケートを書かされる実感を出す。左に紙、背後に敷地（地縄と要望のボリュームの破線）、右に担当者とのチャット。
- 良い点：紙という物が出るので「本物の手順に沿っている」が一目で伝わる。その他要望が空欄のまま、という小さな違和感を置ける。
- 弱点：紙が敷地を半分隠すので、家への集中は弱い。紙の記入は演出（自動で埋まる）にしないと入力が長い。
- 実装の手間：低〜中（静的な用紙＋チャット。用紙の自動記入アニメ0.5日）
- 数字：坪単価・ローンの月々はapp/engine.jsから。色決めと電気の単価は _shared/parts.js の COORD に仮置き（engine.jsへ移す予定）
