## 0. 進め方の決まり（いちばん大事）【Claude】
1. **「できた」と報告する前に、その画面のスクリーンショットを撮る**（Playwright、1920×1080、再生モード `?replay=` で同じ状況を再現）。`out/acceptance/<画面ID>.png` に保存し、下の表の項目を1つずつ見て ○／× を `docs/devlog.md` に書く。×が1つでもあれば「できた」と言わない
2. 見本（`design/v3/...`）がある画面は、見本のスクリーンショットと並べて見比べる。レイアウトの骨格（どこに何がどの大きさで）が違えば×
3. **新しい項目より、×を消すほうが先**。人間から新しい指示が来ても、いま作業中の画面の×を消してから着手する
4. 1つの画面を直したら、**審査員の道（下の1）を最初から最後まで1回通して**、ほかの画面が壊れていないか確かめる
5. 「担当者が応答できませんでした」が1回でも出たら×（自動で1回再送 → それでもだめなら決まり文句で続ける。IMPL_REVIEW_2 の0-7）

## 2. 分岐点：ぬるっと始まって、いつの間にか終わる → 儀式にする【人間の指摘、Claudeが具体化】
- [ ] **始まり**：画面が少し暗くなり、中央に「第二の分岐点」の札が大きく出る（0.6秒）→ 問い「なにを優先する？」が大きく → 2枚の札が左右に大きく並ぶ（メインの領域いっぱい。チャット欄の中に小さく出さない）
- [ ] 札には、名前・総額・月々・**希望との違い**（IMPL_REVIEW_2 の1）・暮らしで変わること1行。自由回答の欄は札の下
- [ ] **選んだ瞬間**：選んだ札が残り、もう一方が下の「選ばれなかった世界線」の列へ飛んでいき、カードが1→3→7→15と増える。家の区画に光の線が一瞬走る（Heroの光の線の部品）
- [ ] **終わり**：「第二の分岐点：〇〇を選んだ」の帯が1.5秒出てから、通常の画面に戻る
- [ ] パートナーの「どうしてそっちにしたの？」は、**いま選んだ札の名前**を引用する。いまのスクショでは第二の分岐点で「切妻／広さ」を選んだのに「予算内に収める（外構は最小限）だね」と言っている（別の分岐の札）。×
- [ ] 理由の入力は任意で、ボタンは「理由を伝える」「言わずに進む」の2つ（「選びなおす」は札の画面で）

## 3. 担当者の話し方：場面ごとに役割を分ける【人間の指摘、Claudeが具体化】
いま、プラン提案の場面でも担当者が掘り下げの質問を続け（庇の深さ、日射をどれくらい遮るか…）、話が進まない。場面ごとにプロンプトを分ける。
| 場面 | 担当者の役割 | 質問 |
|---|---|---|
| 初回打ち合わせ | 聞く（0-5の6段、外から内へ） | 1段に1問＋追加1回まで |
| プラン提案・見積 | **提案を説明し、聞かれたことに答える** | 担当者からの新しい質問は1回まで。答えたら「ほかに気になるところはありますか？」で返す |
| 設計申込（17の調整） | 調整の案を出す | 案の選択を促すだけ |
| 分岐点 | 出てこない（札だけ） | なし |
| 電気・色決め | 確認する（「問題ないでしょうか？」） | なし |
- [ ] 要望を受けたら、まず「承知しました」と受け止め、できること・費用の扱い（エンジンの値）を1〜2文で答える。聞き返しで終わらない
- [ ] **数字は言わせない**：いまAハウスの担当者が「総額の上限は3,128万円を目安に」と言っている（本体価格を総額の上限と取り違え、しかもClaudeが数字を生成している）。×。金額はエンジンの値を、決まった文の差し込みで出す
- [ ] 「反映した要望」に、要望でない事実（「朝はかずが最初に起きる」）や名前を入れない。要望の台帳の言葉だけ

## 4. 電気の打ち合わせ：全画面で【人間】
いまは右のチャット欄の中に小さく出ていて、標準仕様と契約内のオプションが読めない。
- [ ] 電気の場面に入ったら**全画面**（家の絵と世界線の列は隠すか小さく）
- [ ] **左半分**：「標準でついているもの」と「契約で決めたオプション」の一覧を大きく（部屋ごとにまとめる：LDK／キッチン／洗面／寝室／外まわり。項目はアイコン＋字24px以上）。`standard_specs.json` と契約の台帳から
- [ ] **右半分**：担当者の「この内容で進めますが、問題ないでしょうか？」→「この内容でOK」→ その下に要望の候補のタグ（v4のまま）→ 自由入力
- [ ] 契約に入っていないものを頼むと、左の一覧に「追加」として増え、増工の金額（エンジン）が右上のお金の札で数え上がる
- [ ] 打ち合わせで伝えていたのに一覧にないもの（テレビの壁掛けなど）は、**左の一覧にない**ことで気づける作り（伝え漏れの見せ場）
