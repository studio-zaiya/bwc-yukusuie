## 1. 家づくりのプロセス（進捗バーとして常に表示）【人間】

| # | ステップ | ゲームでの主な中身 | デモで見せるか |
|---|---|---|---|

| 2 | 初回打ち合わせ | 来場者アンケート → 担当者のヒアリング（「ご主人は？奥様は？」）。ときに不十分 | 見せる |
| 3 | プラン提案・見積 | 会社ごとの見積の見せ方（台帳③） | 見せる |

| 7 | コーディネート・電気 | 色決め＋アップグレードの勧め。コンセント・スイッチ・照明グレード・エアコン位置・LAN。事前の要望が反映されていないことがある | 見せる（短く） |

- 会社の型によって、ステップの順番と長さが少し違う（例：Aは参考プランで先に契約→詳細はあと、Cは詳細見積まで時間がかかる）【Claude、06の設計に準拠】

## 2. ヒアリングの流れ【人間】

1. 1社目で来場者アンケートを書く（家族構成・予算感・要望の欄）
2. 担当者のヒアリング。「ご主人は？」「奥様は？」と聞かれて要望を伝える。担当者の力量しだいで聞き漏れがある
3. 帰宅後、パートナーまたは暮らしのAIに「伝え忘れたこと、あった？」と聞かれ、自由回答をメッセージアプリかメールで担当者に送る
4. 2社目以降は「同じ要望を伝えた」として、入力を繰り返さない
5. ときどき、担当者が盲点を突く（「エアコンの位置はどうしますか？」）

- 要望は内部で付箋（タグ）に読み替え、どの会社の図面に反映されたか／されなかったかを台帳で持つ（06の「見落としのデータ」）【Claude】

## 3. AIの役割分担

| 役 | 中身 | モデル（案） | 発案元 |
|---|---|---|---|
| 暮らしのAIアシスタント | 施主のスマホの中の汎用AI。予定の通知、相づち、相談への「万能そうな案」。専門的には破綻を含み、最後はプロへの相談に誘導する | 使えるClaude APIの中で最も安価な軽量モデル（実装時に料金表で確認）。ハーネスとロールで縛る | 【人間】 |
| SNSのタイムライン | 投稿は一括生成して保存。傾向（性能派・おしゃれ派・節約派など）と、隣の世界の出来事に由来する投稿を混ぜて呼び出す | 軽量モデルで事前生成／まとめて生成 | 【人間】 |
| 担当者（4社） | ヒアリング、提案、勧め、盲点の指摘。出力は {せりふ, 本音（記録用）} | 中位 | 【Claude】（06準拠） |
| 要望の読み替え | 自由回答を付箋（タグ）と変更の提案に直す。理由も抜き出す | 上位 | 【Claude】（06準拠） |
| 2択の生成と審査 | 対立軸の辞書から生成し、別の役が誘導・不一致を差し戻す | 上位 | 【人間：2択の仕組み／Claude：審査役】 |
| 概略の世界の進行 | 15の世界の担当者の一言（要所で並列） | 軽量 | 【Claude】 |
| 1年後のレポート | 決断の記憶から「守ろうとしたもの」を書く | 上位 | 【Claude】（06準拠） |
| 計算エンジン | 金額・日数・面積・判定。Claudeはtool useで問い合わせる | コード | 【Claude】（06準拠） |
