## 1. いまのPDFの評価

### 残すもの
- 表紙の骨格（縦のロゴ、「わが家の、ちょうどいいバランス」、タイトルの一言、水彩のパース）。水彩が入ったのは大きい
- 「本物の打ち合わせで、聞くこと」のチェックリスト。持ち帰る価値がいちばん高い
- 「起きた／避けた」で、ほかの世界の出来事を自分の注意に変える発想

### 直すもの（重い順）
1. **守れなかった希望が、どこにもない**：総額5,000万円以内 → 5,158万円、月々12万円以内 → 約14.0万円。冬の暖かさを「いちばん大事」と答えたのに「ふつう」。レポートが黙っている（IMPL_REVIEW_2 の9が未対応）
2. **数字が画面とずれる**：16区画のカードでは07の総額が5,078万円、レポートは5,158万円（差の80万円は地盤改良）。どの時点の総額かをそろえる
3. **表紙の絵が、わが家と違う**：Bハウスの寄棟を選んだのに、水彩は切妻。外壁の色も選んだ仕上げと一致しているか不明。絵は家のデータから描く
4. **理由が作り話になっている**：「Bハウスと建てると決めたとき、ふたりで早く前へ進めることを大切に」など、プレイヤーが言っていない理由。3番目は見出し「冬の朝の足もとの暖かさ」と本文（庭・外構）が食い違う。理由は、アンケート・自由回答・打ち合わせの発言・選んだ札の中身という**根拠のあるものだけ**から
5. **「ふたりのバランス」が意味を失っている**：「4つの決断を、だれの思いに寄せて」の帯（あなた1・パートナー3）は、理由を聞くのをやめた今は根拠がない。下半分も空白
6. **付箋が重複し、アンケートの言葉がそのまま**：「車は2台」「外に電気自動車の充電」「外に自転車置き場」が2枚ずつ。「外に物置」のような生の項目。説明文も「ことば、写真、URLから読み取った」と古い
7. **4ページ目があふれている**：16の世界の表がページの下にはみ出して、注記とページ番号に重なり、途中で切れている
8. **余白の偏り**：2・3ページの下半分が空いている一方、4ページはあふれる。カードの大きさが中身と合っていない
9. **担当者のひとことが長く、どれも同じ調子**：「本当にお疲れさまでした」で終わる長文が4つ。読まれない
10. **細部**：表紙と見出しに「あなた と パートナー」と入力した呼び名が入っていない／月々だけ「約140,300円」と円表記（ほかは万円）／札の名前「水回りを二階にまとめるで進める」／本文の灰色の小さな字が紙色の上で薄い

## 3. レイアウトと文字の決まり
- 余白：上下左右18mm。カードの高さは中身に合わせ、ページの下に大きな空白を残さない。あふれそうなら文字を削る（字を小さくしない）
- 字の大きさ（印刷）：本文9.5pt以上、補足8pt以上、見出し14pt、表紙のタイトル28pt前後。本文の色は墨（灰色の本文をやめる。補足だけ濃い灰色で、紙色との対比4.5:1以上）
- 書体：ヒラギノ角ゴ → BIZ UDPゴシック。数字は等幅の数字（表の桁がそろう）
- 金額はすべて万円（小数1桁まで）。差額は「+158万円」。色で良い悪いを塗らない
- 印刷用のCSS（`@page` A4、改ページの位置を固定）で、ブラウザの印刷とPDFの両方で同じに出る
- 1年後の16区画のカードと、レポートの数字は同じ状態から（ずれたら×）
