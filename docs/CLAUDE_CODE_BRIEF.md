## 2.5 決定事項（11/4 12:10〜12:16）

**決定【人間】**
- Hero は design/v3/hero のまま進め、テキストを含む最終調整はClaude Codeで行う
- シンボルマークは B（区画の菱形、design/v3/logo/mark-B.svg）。文字は E のスタイル（丸ゴシックの文字組み）を、日本語・英字とも採用。マークBとE式の文字で、横組み・縦組みのロックアップを作り直す
- スマホ連携は実装を試みる（4章のP1）

**分かれ道の表示と、選ばれなかった世界線の増え方【人間】**
- 主要な分岐には「第一の分岐点」〜「第四の分岐点」と表示する
- 下の「選ばれなかった世界線」は、分岐を経るごとに増える：第一の分岐のあと1、第二のあと3、第三のあと7、第四のあと15（2のn乗−1）。第一の分岐の前は、下の段を出さずにメインを大きくする
- 新しい世界線は、分かれた時点の状態をそのまま引き継いで始まる（エンジンは、決断の時点で世界を複製する作りにする）

**分岐点の置き場所と金額の札（Claudeの提案を人間が承認、11/4 12:16）**
- 4つの分岐点の名前と順番は、動画の前振りと同じ「だれと建てる？／なにを優先する？／いくらまでかける？／どう仕上げる？」に固定する。家づくりの手順への置き場所の案：
  - 第一（だれと建てる？）：プラン提案・見積のあと、会社を1社に決めるとき
  - 第二（なにを優先する？）：設計申込・詳細打ち合わせ（間取りと予算の配分）
  - 第三（いくらまでかける？）：契約前の最終見積とローン本審査のとき → 契約の前なので、金額の札は「見積の変更」として動く
  - 第四（どう仕上げる？）：契約後のコーディネート・電気（外壁や仕様のアップグレードを受けるか）。これまでの「箱型か勾配屋根か」は、設計の段階の決めごとなので第二に含める
- 「窓をトリプルガラスにしたい」は、第三の分岐点での自由回答の例（06の「最初に通す1本の筋」）で、分岐点そのものではない
- 右上の金額の札：「総額（土地＋建物）」と「借入」を並べ、下に小さく「自己資金」。契約後は「総額＝土地＋契約金額＋増工」。建物だけの見積と、土地込みの借入を並べない（実務でも見積は土地＋建物の総額で出す【人間】）
- エンジンの直し：`DECISIONS` の第二に屋根の形（箱型／勾配）を含め、第四を「コーディネートでアップグレードを受けるか」に差し替える。第三は契約前に置く
- 2択の外の答えの回収（読み替え → 対立軸と状態変数に落とす → エンジンで帰結を保証）が、本作のAIの作り込みの中心。ここに時間をかける【人間・Claude】

## 3. 全体の構成【Claude】

- **Cloudflare Workers**（有料プラン加入済み【人間】）＋静的アセット配信。1つの Worker で `/`（画面）と `/api/*`（Claude呼び出し・保存）を担う
- **画面**：素のJavaScript（ESモジュール）。フレームワークは使わない（試作の資産をそのまま移せるため）
- **エンジン**：`app/engine.js` をESモジュールにして `src/engine/` へ。画面と Worker の両方から同じものを読む
- **Claude呼び出し**：Worker から Anthropic API。APIキーは `wrangler secret` に置き、ブラウザに出さない
- **保存**：プレイの記録（出来事の列）は画面側で持ち、区切りごとに Worker 経由で KV に保存（レポートの再生コード用）
- **モデル**：役割ごとに環境変数で切り替え可能にする。既定値は実装時に公式ドキュメントで料金と提供状況を確認して決める
  - 上位（要望の読み替え、2択の生成と審査、自由回答の読み替え、レポート）：Sonnet 系
  - 中位（担当者、進行）：Sonnet 系または Haiku 系
  - 軽量（自分のAI、15の世界の一言、SNSの事前生成）：使えるうちで最も安い Haiku 系【人間：自分のAIは最も安価で低機能なもの】

4. **自由回答の取引（核）**：Claude が入力を「変更の提案」に読み替え → **tool use でエンジンに問い合わせ**（quote／loanCheck／schedule／coverageCheck）→ 条件を示す → 承認 → 確定

5. **プレイの通し（1本の筋）**：起動 → 世帯 → 区画 → P1アンケート → ヒアリング（担当者のチャット）→ 伝え忘れ → プラン・見積 → 分かれ道×4 → コーディネート → 電気 → 契約 → 早送り（着工〜上棟〜施主検査）→ 引渡し（W4）→ 1年後（16区画・再生・担当者の事情・見積の透視）→ レポート

   - 「選ばれなかった世界線」の15区画は、フェーズごとに工程が進む
6. **自分のAIに聞く**：1ターン1回、短い回答を1回だけ。質問が間取り・配置・動線のときだけ、部屋の並びのJSONも返させ、コードで略図に描く【Claude：判定はコードで】
7. **SNSを見る**：`data/sns_posts.json`（期間中にスクリプトで一括生成。話題と立場の印つき）から、いまの話題の投稿を3〜5件、立場を混ぜて出す
8. **担当者のアバター**：応答中は「考え中」、文字が流れる間は「話す」、終わると「笑顔」→「待機」。CSSクラスの切り替えだけ
9. **回数制限と費用の上限**：1人あたり1日のプレイ回数、全体の1日の呼び出し上限、緊急停止の環境変数
10. **レポート**：画面版と印刷版（A4・3ページ）。数字はエンジン、言葉はClaude（決断の記憶から）
11. **入口の写真**：PCの画面への写真のドロップと、スクショの貼り付け（クリップボード）。送る前に縮小（長辺1568px程度、撮影場所などの埋め込み情報も消える）

## 5. 動画のための仕組み【Claude】
