# 08 Claude API の費用の試算と上限の設計（v0.1、2026-11-04 午後）

作成：Claude Code。発案元：【人間】クレジットを制作中のテストで使い切らない手順にする／【Claude】以下の試算と仕組み。
料金は 2026-10 時点の公表値（ドル／100万トークン）：Sonnet 5.5 入力2・出力10、Haiku 5.5 入力0.1・出力0.5。

## 1. 1プレイあたりの呼び出しと費用（見込み）

| 役 | モデル | 回数／プレイ | 1回の目安 | 小計 |
|---|---|---|---|---|
| 自由回答の取引（tool use の往復、最大4往復） | Sonnet 5.5（effort low） | 1〜4（ふつう2） | 約0.05ドル | 0.05〜0.20 |
| レポート | Sonnet 5.5（effort low） | 1 | 約0.025ドル | 0.025 |
| 担当者（ヒアリング・伝え忘れ・電気） | Haiku 5.5 | 約5 | 約0.0005ドル | 0.003 |
| 自分のAI | Haiku 5.5 | 0〜12 | 約0.0004ドル | 〜0.005 |
| 15の世界の一言（並列） | Haiku 5.5 | 15（1プレイに1回の並列） | 約0.0003ドル | 0.005 |
| **合計** | | 呼び出し 約10〜25回 | | **ふつう 約0.1〜0.15ドル、多くて 約0.25ドル** |

- 失敗時の再試行（1回）が全部に起きた最悪でも、1プレイ約0.5ドル
- 費用のほとんどは「自由回答の取引」。ここは本作のAIの中心なので Sonnet のまま残す
- 担当者を Sonnet から Haiku に下げた（中位のモデルを `MODEL_MID=claude-haiku-5-5`）。1プレイの費用が約2割下がる。口調が物足りなければ、環境変数だけで Sonnet に戻せる

## 1.5 実測（11/4 13:43、本番）

- 役割ごとに1回ずつ（`scripts/api_smoke.mjs`）：取引 0.025ドル（7.0秒、道具を4つ呼んで submit）、担当者 0.0002ドル、自分のAI 0.0001ドル、レポート 0.006ドル。合計 0.031ドル
- 本番URLでの通しプレイ1回（`scripts/playthrough.cjs`、自由回答の取引1回・ヒアリング3回・電気1回・15の世界の一言・レポート）：**0.034ドル**
- 試算（1プレイ0.1〜0.25ドル）の約4分の1。審査で300プレイされても約10〜30ドルの見込み

## 1.6 担当者を Sonnet 5.5 に戻した（11/4 14:47、人間の判断）
- 担当者の受け答えを重く見て、`MODEL_MID=claude-sonnet-5-5`。1回 約0.005〜0.01ドルで、1プレイに6〜10回 → 1プレイ 約0.1ドル前後の見込み（Haiku のときは約0.05ドル）
- 審査で300プレイされても約30ドル。上限（1日25ドル・累計150ドル）の内に収まる

## 3. 使いすぎを防ぐ仕組み（実装済み）

- **ドル建ての上限**：呼び出しのたびに、実際のトークン数から費用を計算して KV に足す。`DAILY_BUDGET_USD`（1日、既定10ドル）と `TOTAL_BUDGET_USD`（累計、既定100ドル）を超えたら、Claudeを呼ばずに代わりの文で返す（ゲームは止まらない）
- **回数の上限**：1人（IP）あたり1日6プレイ、1日120回の呼び出し。全体で1日4,000回
- **緊急停止**：`EMERGENCY_STOP=1`
- **開発中は既定で呼ばない**：ローカルの `.dev.vars` に `AI_MODE=mock`。本番だけ `live`
- 使った額は `/api/health` の `usdToday`・`usdTotal` で見られる。呼び出しの記録にも `costUsd` が残る

## 4. 人間に決めてほしいこと

- 支給されたクレジットの額（`TOTAL_BUDGET_USD` を、その額の半分程度に合わせる提案）
- Anthropic Console の使用額の上限（Spend limit）も、同じ額で二重にかけておくと安心
