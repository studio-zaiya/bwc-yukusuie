## A. 先に直すべき不具合（P0）

### A1. 担当者と自分のAIが、決まり文句しか返していない【誠実さ・審査員】
- 担当者が、何を言っても「ありがとうございます。いまのお話、プランに反映できるか確認しますね。」を返している。断熱等級とUA値を聞いても同じ文が返る
- 自分のAIも「いまは詳しくお答えできません。担当の方に、いちど確かめてみてください。」だけ
- **Claudeが実際に呼ばれているか、失敗して代わりの文に落ちているかを確かめる。** 失敗したときは、開発中は画面の隅に小さく「応答できませんでした（再試行）」と出し、記録に残す。代わりの文で成功したように見せない
- 担当者の答えに数字が要るとき（断熱等級、UA値、金額）は、エンジンの値を tool use で取って答える。UA値はエンジンに等級ごとの値を持たせる（Claudeに作らせない）

### A2. 会社ごとのチャットの記録が混ざっている【UI・実務】
- Cデザインの画面に、Aハウスの高橋の発言（「ご連絡ありがとうございます。プランに反映して…」）が出ている
- 記録は会社ごとに分ける。2社目以降は「前の会社と同じ要望を伝えた」の注記だけを出し、要望の中身は内部の台帳で共有する

### A3. 「あなたの家」の番号が、途中で 07 から 09 に変わる【審査員・UI】
- 決断の結果から番号を計算しているためと思われる。プレイヤーの家の番号は最初から最後まで固定する（例：常に07）。ほかの世界線は、プレイヤーを除いた番号を割り当てる

### A4. 借入の上限と、選択肢の判定が食い違っている【実務】
- 第一の分岐点で、Aハウスの選択肢に「借入5,031万円（審査の上限を超える）」と出る。この時点でAが事実上選べず、「Cに寄る」偏りが再発する
- 第三の分岐点では「借入4,795万円」が上限4,790万円を超えているのに、何も表示されない
- 自己資金が200万円、借りられる額が4,790万円なので、世帯は型1（年収680万円）になっている。**引き継ぎでは型2（年収800万円、家に入れる預金350万円）を推奨**。型を確認して、どちらかにそろえる
- 大手の担当者は、予算を超えると面積や仕様を落とした案を出し直すのが実務の普通の動き。Aの見積が上限を超える場合は、「この予算に合わせた案」も添えて、Aを選べる状態にする
- 上限の判定は、全部の選択肢で同じ規則で行う

### A5. 金額に小数が出ている【UI】
- 「4,919.8万円」「増工 64.8」。金額の表示は万円単位の整数に丸める（計算の内部は小数のままでよい）

### A6. レポートが、中身のない型のまま出ている【審査員・誠実さ】
- 「先に伝えておきたいこと」が「1. いちばん大切にしたいこと 2. 予算の上限と、その理由 3. 後から変えにくいところ」という**見出しだけ**になっている
- 「悩んだら、これを優先する」も、プレイの内容から導かれていない一般論
- 「あのとき守ろうとしたもの」が見出しに2回出て、中身は「〜を選びました」の繰り返しで、理由がない
- 理由が取れていないのが原因。2択を札で選んだときも、選んだ直後にパートナーの一言（「どうしてそっちにしたの？」）で任意に理由を聞くか、それまでの会話から抜き出す
- 「1年後のあなたの家（エンジンの値）」の「エンジンの値」は外す（v4：仕組みの名前を画面に出さない）

### A7. 時計の札の論理がおかしい【実務】
- 10日目（プラン提案のころ）に「ローン特約の期限まで80日」と出ている。ローン特約は土地の契約のあとに始まる。この時点で出すべきは「土地の契約期限まで○日」

### A8. まだ決まっていないことが、決まったように表示されている【実務】
- 初回打ち合わせの時点で「32坪・総二階　箱型の屋根」と出ている。屋根の形は第二の分岐点で決まる。決まるまでは「未定」か、要望から計算した面積の目安だけにする
- 坪数は、引き継ぎの「総二階33〜35坪」とずれている（32坪）。要望から計算して出す

### A9. 話す人が切り替わらない【UI】
- 担当者が「奥様は、いかがですか。」と聞いたのに、答えが「かず」の名前で記録されている。担当者の質問に合わせて、話す人の選択を自動で切り替える（手で戻すこともできる）

## B. 体験として弱いところ（P0〜P1）

### B1. 「伝えたのに入っていない」と「伝えていない」を区別していない【実務・審査員】
- 帰り道に「エアコンはルーバーに隠したい」と送り、担当者は「プランに反映して、お持ちしますね」と答えた。それなのに電気の打ち合わせの標準仕様に入っていない
- これはこの作品のいちばんの見せ場（前の工程の伝え漏れが後で響く）。指摘したときの返事を分ける
  - 伝えていた要望が漏れていた → 担当者が謝り、会社の力量しだいで「無償で直す」「差額は半分」「記録がないので追加」に分かれる（議事録の有無が効く）
  - 一度も伝えていない → 「契約には入っていないので、追加になります」
- この区別は、エンジンの「見落としのデータ」（06の8章）で持つ

### B2. 帰り道の画面が、だれと話しているのかわかりにくい【UI】
- 見出しは「帰り道　ゆう」なのに、同じ画面に担当者の返信が出る
- ゆうとの会話 →「高橋さんに送る」→ 翌日、メッセージアプリふうに担当者から返信、と場面を分ける。返信は少し時間をおいて届く演出にする

### B3. 担当者のヒアリングが浅すぎ、会社の差が出ない【実務】
- 2問聞いて「確認しますね」で終わる。会社ごとに聞き方の深さを変える（例：Cは暮らしの時間帯や収納の量まで聞く、Aは予算と時期を先に詰める、Bは規格プランの選択肢を見せる、Dは「全部できますよ」と言う）
- 不十分なヒアリングは狙いどおりでもよいが、それが会社の個性として描かれていること

### B4. 選ばれなかった世界線のカードが、記号的で単調【審査員・UI】
- 「左左」「左右」「右右」という名前は、見る人に意味が通じない。分岐ごとの選択の短い名前（例：「A・勾配屋根」）か、第四の分岐点のあとは呼び名にする
- 同じ会社の世界が、全部同じひとこと（「契約の日取りを決めた」）になっている。世界ごとの出来事や、並列で呼ぶ担当者の一言で変化を出す
- 番号は、15個がそろったあとに付ける

### B5. 家の絵が、段階を追って変わらない【審査員】
- 初回からコーディネートまで、同じ半透明の箱のまま。v4の2-1の段階（各社の立体 → 点線 → 確定 → 色の見本 → 工事で立ち上がる）を実装する

### B6. 第四の分岐点が、コーディネートの画面とつながっていない【UI】
- いまは2択の札だけ。v3のP4-a（外壁・床・内壁を選び、色が家に載る）で選んだ結果が、そのまま第四の分岐点の答えになる形にする

### B7. 起動画面が文字だけ【審査員】
- マークB＋E式の文字のロックアップ、分譲地の絵、「16の世界をAIにまかせて見る」（1回遊ぶと開く）を入れる（v3のS1）

## E. 住宅会社を選ぶまでの流れを作り直す（P0）【人間の指摘、11/4 13:45】

いまは、事前の情報収集なしに、いきなりA〜Dの見積の札から2社を選ばせている。会社名と価格だけを見れば、だれでもAとCを選ぶ。次の流れに変える。

1. **情報収集（見学・相談のステップ）**【人間：評判や情報収集のフェーズ／Claude：中身】
   - 入口を5つほど並べる：住宅展示場、完成見学会、知人の口コミ、SNS、ネットの比較記事、チラシ
   - それぞれから、会社についての断片的で偏った情報が得られる（例：Aは展示場が立派で性能の話が上手／Bは価格が明快、知人は「早かった」／Cは口コミで「聞き取りが丁寧、ただ待たされた」／Dは近所の先輩が「社長がいい人」）。正解は示さない。良い話と気になる話を、どの会社にも混ぜる
   - **価格はこの段階では見せない**（チラシの「本体価格〜」程度は可）
   - 集めた情報から、**実際に訪ねる2社**を選ぶ
2. **1社目のヒアリング（深く、多岐にわたって）**【人間】
   - アンケート → 担当者のヒアリング。話題は、暮らし方と家族の時間帯、収納と家事の動線、予算と資金、土地、性能、デザイン、将来の変化など
   - 担当者は専門家としての人格を持つ（会社の型と担当者の力量で、聞き方の深さと抜けが変わる。抜けは記録として残し、後の工程で効かせる）
   - 帰り道：パートナーとの会話 → 伝え忘れを**その会社の担当者だけに**送る → 翌日、返信が届く（B2のとおり、場面を分ける）
3. **2社目のヒアリング**
   - 「前の会社と同じ要望を伝えた」と注記 → 2社目の担当者が、その会社の視点で質問や助言をする（2〜4往復）
   - **2社目のチャットは、1社目とは別の記録で始める**（A2）
4. **提案と見積の見比べ（2社）**
   - 上にタブ（2社）、左に見積（その会社の見せ方）、右に提案とポンチ絵。それぞれの担当者に質問できる
5. **第一の分岐点「だれと建てる？」**：この2社から選ぶ
- 訪ねなかった2社は、情報収集・SNS・1年後の街の様子の中にだけ出る
