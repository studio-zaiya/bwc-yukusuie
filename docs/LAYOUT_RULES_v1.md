# 間取りの組み立て v1（作り手の決まりから、型で組む）

作成：2026-11-07 12:00（claude.ai の Claude）。発案元：1階の決まりのすべて（南向き、LDKは南、玄関は東か東南、水回りは北に一列、LDKの3つの型、畳を入れて田の字、トイレだけ玄関側）【人間・作り手の実務の知見を、期間中に口頭で】、データの形・2階の仮の決まり・検査と描き方【Claude】。
Claude Code（実装担当）へ：時間は1〜2時間。**別のブランチで作業し、公開URLは人間の確認のあとに切り替える。**

## 0. いちばん大事な制約：絵だけを差し替える【人間、11/7 12:34】
- ねらいは、**金額や実態とは関係のない、それっぽいポンチ絵**を出すこと。いまの絵がプレゼン上あまりに荒いので、見た目だけを少し直す。それ以上のことはしない
- 変えるのは**間取りの絵（ゾーニング図）の描き方だけ**。次のものは**一切変えない**
  - 金額・延床・工期などの計算（エンジン）、設計担当（planner）のプロンプトと道具、担当者の会話
  - 外観の立体（3D）、区画の絵、切り絵、水彩、レポートの数字
  - 出来事の記録の形（イベント）、再生（`?replay=`）
- 新しい描き方は、**いまの提案のデータを読むだけ**（読み取り専用）。延床、会社、要望の一覧、すでに決まっている金額を読んで、絵を組む。絵の結果を、ほかのどこにも書き戻さない
- **作り始める前に、いまの間取りの結果がどこで使われているかを全部洗い出す**【人間、11/7 12:44】
  - 間取りを作る関数・その結果のデータ（部屋の一覧、座標、面積など）を、リポジトリ全体で検索し、**読んでいる所をすべて一覧にする**。画面、エンジン、3D、区画、切り絵、水彩、レポート（印刷）、記録・再生、Worker、テスト、動画の場面ファイルまで
  - 例外は作らない。「関係なさそうだが読んでいる」所も一覧に入れる
  - 一覧を人間に返してから作り始める。**絵の表示以外の所で使われていたら、そこは触らない**。新しい絵は別の部品として足し、古い結果はそのまま残して、ほかの所は古い結果を読み続ける
- **古い絵と新しい絵を混ぜない**【人間、11/7 12:44】
  - 間取りの絵を出す所は、すべて1つの入口（例 `drawZoning()`）を通す。設定1つで、全部が新しい絵か、全部が古い絵になる。画面によって古い絵と新しい絵が混ざる状態を作らない
  - 提案の日、分岐点の札、16区画で区画を押したとき、レポート、再生、のすべてで、同じ絵が出ることを確かめる
  - 古い記録を再生したときも、新しい絵で出る（記録の中身は変えず、描き方だけが新しい）
- 作り方：新しいファイル（例 `src/web/zoning.js`）に描画だけを書き、提案の画面で、いまの間取りの絵の代わりにこれを呼ぶ。元に戻すスイッチ（設定1つ）を残す

## 0.5 目的は「ゾーニング」まで【人間】
- 出すのは、厳密な間取りではなく、**ゾーニングのコンセプトが一目でわかる図**。寸法は厳密でなくてよい。計算に使うのは延床（30何坪）などの数だけ
- 考え方は一つ：**メイン空間は南、水回りは北、それ以外は余ったところに埋め込む**
- 外形はいつも**長方形（正方形に近い）**に保つ。画面に収まりやすく、ゾーニングも読みやすい

## 2.5 1階が広くなる要望のとき【人間】
- 「1階に主寝室」など1階が広くなる話は、まず基本形（正方形）で2の決まりどおりに描く
- そのうえで、**主寝室をリビングの横にドカッと張り出してくっつける**
- もう一つの形【人間、11/7 12:03】：LDK を**縦長**（北からキッチン・ダイニング・リビング）にして、**その隣の南に主寝室**を並べる。空いた L 字の所に、水回りを要望より少し小さめにまとめて入れる（または、水回りを東か西の側に一列に並べる）。試作の見本はこちらの形
- 張り出して外形がでこぼこになったら、**空いたところを収納などの四角で埋めて、外形を長方形にもどす**
- 1階が広くなった分、2階は小さくしてよい（総二階でなくてよい）。延床の計算はエンジンのまま

## 2.6 どうしても収まらない要望のとき【人間】
- 決まりで組めないほど変わった要望は、無理に組まない。**基本形の普通の間取りを出し**、絵の下に小さく「ご要望のすべては、この図には入れきれていません」と書く
- 担当者の会話・記録・レポートには足さない（0の制約）

## 1. 前提
- 敷地はすべて南向き（道路は南）。建物は総二階、ほぼ正方形
- グリッド 910mm。1階はおよそ 8×8 マス（約7.3m角、約17坪）。延床に合わせて 7〜9 マスで伸び縮み
- 1階を「南の帯」と「北の帯」と「残り」に分ける

## 2. 1階の決まり【人間】
1. **リビングは南。** LDK（メインの空間）は、**南西か南東の角**に置く
2. **玄関は東か東南。** 玄関とホールは「残り」の場所に
3. **水回りは北に一列。** 浴室・洗面・トイレ（とキッチンの背の側）を、北の帯にまとめる
4. **水回りが多いとき**（要望でトイレ2か所、広い洗面、ランドリーなど）：**トイレだけ玄関の近くへ**出し、残りは北に
5. **LDK の型は3つ**
   - **直線型**：キッチン・ダイニング・リビングが一直線の細長い長方形に並ぶ。**南側の全部を LDK が占める**（リビング約8畳、ダイニングテーブルが置ける幅、そこにキッチン）。玄関は**東の真ん中**から入れ、北に水回り、LDK と北の帯のあいだに玄関・ホール・収納【人間、11/7 12:03】
   - **L型**：キッチンの正面か横にダイニングのテーブル、L の余ったところにリビング
   - **田の字型**：畳スペースの要望があるとき。リビング・ダイニング・キッチンで3ブロック、残る1ブロックに畳。2×2 の4ブロックになる
6. **階段は描かない**【人間、11/7 12:30】。階段の位置（リビング階段かホール階段か）は、AIで間取りを描くときにいちばん難しく、リビング階段の要望に対応しきれないため。階段のあたりは「ホール」として、曖昧にしておく
   - 将来、描く場合の決まり【人間】：ホール階段はホールの中。リビング階段は、ダイニングの横から上がるか、リビングのソファの後ろかテレビの裏から上がる。階段の上は吹き抜けになることがあり、2階の組み方が難しくなる（今回はやらない）

## 3. 2階の決まり【人間】
1. **主寝室を先に置く。** 6畳か8畳を、まずドカンと置く（南の帯）
2. **余ったところに子ども部屋を並べる。** 4.5畳から。小さくてよい人は3畳も可
3. **空いたところに、収納とトイレを詰める。** 2階のトイレは、1階の水回りの上（北）に寄せる【Claude の補足】
4. **書斎などの細かい要望**は、主寝室と子ども部屋で余ったところに、四角を1つ置いて名前だけ書けばよい
5. **子ども部屋が減る、主寝室が小さい**などの要望は、それに合わせて上の順で詰め直す
- 2階は難しくしない。上の順に「大きいものから置いて、余りに詰める」だけ
- 階段は描かない（1階と同じ位置を「ホール」にしておく）

## 4. 絵のコードが選ぶもの（いまのデータから。Claude は呼ばない）
```json
{
  "ldk_type": "straight | L | tanoji",
  "ldk_corner": "SW | SE",
  "entrance": "E | SE",
  "toilet_near_entrance": true,
  "master_on_1f": false,
  "fallback_basic": false,
  "sizes": { "ldk_tatami": 18, "tatami_room": 4.5, "master_bed": "6 | 8", "kids": ["4.5", "4.5"], "extra_rooms": ["書斎"] },
}
```
- 選び方：要望の一覧の言葉から決める。畳スペースの要望 → `tanoji`。広いLDK・対面キッチン → `L`。コスト優先・コンパクト → `straight`。会社ごとの好み（A は直線、C は L など）で、16の世界の見た目に違いを出す
- 外形の大きさは、**いまの提案の延床**に合わせて伸び縮みさせる（絵のために延床を変えない）。畳数は絵の中の目安で、画面のほかの数字とは別

## 4.5 2社の案を、同じ要望から振り分ける【人間の案、11/7 12:32。具体は Claude】
- 決まりが1つだと、2社とも同じ間取りになって比べられない。そこで、**同じ要望から候補をいくつか作り、その場で2社に振り分ける**
- 候補の作り方：LDK の型（直線／L型／田の字）、要望の部屋を入れる・入れない（畳、書斎、ランドリーなど）、角（南西・南東の左右反転）、玄関（東・東南）を組み合わせて、4〜8案
- 金額は**いまの2社の提案の金額をそのまま使う**（新しく計算しない）。絵のコードは、候補ごとに「要望への近さ」だけを数える
- 振り分け：**金額が高いほうの会社**に要望寄りの絵、**安いほうの会社**に要望をしぼった絵を当てる（いまの金額と、絵の印象が食い違わない）
  - 1社は「**要望に近いが、金額は高め**」の案
  - もう1社は「**金額は抑えたが、要望を一部しぼった**」案。要望が入っていなかったり、ずれていたりしてよい（現実の提案でもよくある）
  - 2社の案は、型か左右のどちらかを必ず変えて、見た目でも違いがわかるように
- 絵の下に「**図に入らなかった要望**」を小さく出す（例：畳スペース、書斎）。**絵の中の注記だけ**で、担当者の会話・記録・レポートには入れない
- 階段の要望（リビング階段など）は、図に描かないので「図に入らなかった要望」には数えない【Claude】
- 見本：`docs/layout_proto/zoning_pair.png`（同じ要望から、Cデザインは田の字＋書斎、D工務店は直線型で畳と書斎をしぼった案）

## 4.6 会社ごとの間取りの癖（エンジンは1つのまま）【人間の案、11/7 12:33。入れ方は Claude】
- 会社ごとにルールやエンジンを4つ作らない。**同じ組み立てに、会社ごとの「癖の数」をいくつか渡すだけ**にする
- 癖の数は、絵のファイルの中の小さな表（または `standard_specs.json` の各社に `layout_style`）。**なければ標準の値**で動く。エンジンはこの値を読まない
- 癖の数（目安。値はエンジンが使う割合）
  | 会社 | 人間の描いた個性 | 外形の大きさ | LDK の割合 | 収納の割合 | 個室・廊下 | 好む型 |
  |---|---|---|---|---|---|---|
  | Aハウス（大手） | 空間が大きく、ゆとりと高級感 | 大きめ（+1マス） | 大きめ | ふつう | ふつう | L型 |
  | Bハウス | 規格・ローコスト寄り | 標準 | ふつう | ふつう | ふつう | 直線型 |
  | Cデザイン | 収納は少ないが、同じ面積でリビングが広い | 標準 | 大きく | 少なく | 少なく | L型・田の字 |
  | D工務店 | 面積が足りないとLDKが小さめ（16畳ほど）、収納・子ども部屋・廊下が多め | 標準 | 小さめ | 多く | 多め | 直線型 |
- 使い方
  1. 4.5 の候補を作るときに、会社の「好む型」を先に試す
  2. 組み立てで、外形と LDK・収納の割合を少しだけ伸び縮みさせる（LDK の奥行きを0.5マス足す／引く、ファミリー収納を LDK に含める／分ける、など）
  3. 割合の差は小さくてよい。2社を並べたとき「なんとなく性格が違う」程度
- 「外形の大きさ」は、いまの延床の範囲での見せ方だけ（延床や金額は変えない）
- 優先の順番：時間がなければ、**まず「好む型」だけ**（1行の設定で効果が大きい）。次に外形、最後に割合
- 検査（6）は全社共通。癖で決まりを破らない（LDK は南、水回りは北）

## 5. 組み立てのコード（エンジン）
- 型ごとに、8×8 マスの部屋の割り付けを持つ（`ldk_corner` が SE なら左右反転、`entrance` で玄関の位置を変える）
- 延床と要望に合わせて、マスの数を伸び縮み（LDK を広げる、畳を足す）
- できた案を、下の検査にかける。落ちたら、型の中の別の割り付けを試す。それでもだめなら、いちばん点の高い案を使う（記録には残さない）

## 6. 検査（コードで数える）
- LDK が南に面している／玄関が東か東南
- 水回りが北の帯にまとまっている（トイレだけ玄関の近くは可）
- 玄関から LDK まで、廊下2マス以内で入れる
- 廊下が全体の1割以下
- 2階：主寝室6畳以上、子ども部屋3畳以上、2階のトイレが1階の水回りの上

## 7. 描き方
- ゾーニングの図として：部屋ごとの四角、部屋名と畳数、南の向きの印（階段は描かない）
- 色分け【人間、色の値は Claude】。あまりバラバラにしない。字（墨 #1E2B36）が読める明るさで、四角の線は墨の細い線
  | ゾーン | 色の考え | 値（目安） |
  |---|---|---|
  | メイン空間（LDK） | 明るい、うすい黄 | #FBEFC4 |
  | 畳スペース | イグサの色、うすい黄緑 | #DDE7B8 |
  | 水回り（浴室・洗面・トイレ・ランドリー） | 水の、うすい水色 | #D5EBF4 |
  | そのほか（玄関・ホール・廊下・収納） | 字が飛ばない、うすいグレー | #ECEAE5 |
  | 2階の主寝室・子ども部屋・書斎 | メイン空間と同じ系統で、少しだけピンク寄り | #F7E4DA |
  - 2階のトイレ・洗面は水色、ほかはグレー（1階と同じ）
  - 部屋名の字は墨、畳数は墨のうすい色。色だけに頼らず、部屋名でも区別できる
  - 会社に色は付けない決まりはそのまま（この色はゾーンの色）
- 余裕があれば：910mm のグリッド、壁の太さ、扉の開き
- 今の水彩やアイソメの家の絵と、形（外形）がそろうこと
