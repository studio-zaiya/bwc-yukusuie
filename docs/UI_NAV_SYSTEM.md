# 進み方のUIの決まり（ボタンの階層・置き場所・言葉）

作成：2026-11-05 03:20。発案元：問題の指摘と「プロ目線で一貫性とナビゲーション性を高める」【人間】、決まりの中身【Claude】。
Claude Code へ：全画面に共通で当てる。新しい画面を作るときも、この決まりに従う。完成の判定は ACCEPTANCE の7に足した行と、yukusuie-friendly の監査で。

## 1. いまの問題【人間】
- 次へ進むボタンが小さく、色もほかのボタン（「送る」「写真やURLを見せる」）と同じ墨の塗りで、UIに埋もれる
- 置き場所が画面ごとにばらばら（チャットの中、左下、右下、カードの下）で、どう進めばいいか迷う

## 2. ボタンは3段の階層だけ【Claude】
| 階層 | 役目 | 見た目 | 1画面に |
|---|---|---|---|
| **進む**（主） | 次の場面・工程へ進む。ゲームを前に進める唯一のボタン | 墨の塗り、白字、高さ56px以上、字20px以上（太字）、右端に「▶」。角丸は大きく | **1つだけ** |
| **答える・選ぶ**（副） | 選択肢、札、「この内容でOK」、調整の案 | 紙色の地に墨の線（2px）、字18px以上。選ぶと墨の地に変わる | いくつでも |
| **寄り道**（補助） | SNSを見る、自分のAIに聞く、写真やURLを見せる、元の案に戻す、くわしく見る | 線のない文字のボタンか、小さな線のボタン（字16px）。アイコンつき | いくつでも |
- 墨の塗りは「進む」だけに使う。いまの「送る」は墨の塗りなので、**入力欄の中の右端に置く送信のアイコンボタン**（紙飛行機の形、墨の線）に変える。Enterで送れる
- 「進む」は、押せないとき（返事を待っている、必須の選択がまだ）は薄くし、ボタンの上に理由を小さく出す（「担当者の返事を待っています」）

## 3. 「進む」の置き場所は、全画面で同じ【Claude】
- 画面の**右下に固定した進行の帯**（高さ88pxほど、紙色、上に細い線）を全画面に置き、「進む」はいつもその帯の右端
- 帯の左側には「いまやること」の1行（下の4）
- チャットの中や、カードの下に「進む」を置かない（会話の流れの中に埋もれるため）
- 分岐点の儀式の画面では、札を押すこと自体が選択。札を選んだあとの「この道で進む ▶」も、同じ帯の右端に出る
- スマホの幅でも同じ帯（下端に固定）

## 4. 「いまやること」の1行【Claude】
- 進行の帯の左側に、いまの場面でプレイヤーがすることを1行で（20字前後）。例：
  - 「アンケートに答えましょう（あと8問）」
  - 「担当者の質問に答えましょう」
  - 「2社の提案を見比べて、建てる会社を選びます」
  - 「色を選んで、仕上げを確定しましょう」
  - 「16の区画を押して、ほかの世界を見てみましょう」
- 「進む」が押せるようになったら、この1行が「準備ができました。次へ進みましょう」に変わり、「進む」が一度だけ軽く脈打つ（0.6秒。動きを減らす設定では色の変化だけ）
- 事前に何が起きるかの予告は書かない（CLAUDE.md）。操作の案内だけ

## 5. 「進む」の言葉は「行き先＋▶」でそろえる【Claude】
| 場面 | いま | 直す |
|---|---|---|
| 分譲地 | 会社を探しはじめる | 家づくりをはじめる ▶ |
| 情報収集 | この2社を訪ねる | この2社を訪ねる ▶（このままでよい） |
| 1社目の打ち合わせのあと | 打ち合わせを終えて、帰宅する | 帰り道へ ▶ |
| 帰り道のあと | 2社目を訪ねる | 2社目へ ▶ |
| 2社目のあと | 2社を見比べて、第一の分岐点へ | 提案の日へ ▶（FLOW_v3） |
| 分岐点で札を選んだあと | （まちまち） | この道で進む ▶ |
| 契約 | — | 契約する ▶ |
| 色決め | この仕上げで確定 | 仕上げを確定する ▶ |
| 電気 | この内容でOK | 「この内容でOK」は副のボタンのまま。確定後に「着工へ ▶」 |
| 早送り | 着工する ▶ | 着工する ▶（このままでよい） |
| 1年後 | レポートを受け取る | レポートを受け取る ▶ |
- 言葉は短く（10字前後）。「〜して、〜へ」のように2つの動作を1つのボタンに詰めない

## 6. そのほかの一貫性【Claude】
- **戻る**：「＜ 戻る」は進行の帯の左端に置ける場面だけ（アンケート、色決め）。分岐点を確定したあとは戻れない（世界が分かれたため）
- **画面の切り替え**：すべて0.25秒のフェード＋少し横へ（IMPL_REVIEW_2 の14）。新しい場面では、見出し（場面の名前）を左上の同じ位置に
- **ポップアップ**（SNS、自分のAI、決断の履歴）：同じ形の下からのシート。閉じるは右上の「×」とEsc、シートの外を押しても閉じる
- **場面の名前**：左上の「07 あなたの家」の横に、いまの場面の名前（「初回打ち合わせ」「提案の日」「契約」）を同じ大きさ・位置で
- **案内（スポットライト）**は、進行の帯と「進む」を最初に1回指す（「迷ったら、右下のボタンで進めます」）

## 7. 受け入れ基準
- [ ] どの画面でも、「進む」は右下の進行の帯の右端に1つだけあり、墨の塗りで、ほかのボタンより明らかに大きい
- [ ] 墨の塗りのボタンが、「進む」以外にない（「送る」は入力欄の中のアイコン）
- [ ] 進行の帯の左に「いまやること」の1行がある。押せないときは理由が出る
- [ ] 「進む」の言葉が「行き先＋▶」で、10字前後
- [ ] 1280×720 の画面でも、進行の帯がほかの要素に重ならない
