# 要望の聞き方 v2（IMPL_REVIEW_2 の0-5を置き換える）

作成：2026-11-04 17:40。発案元：流れの骨格は【人間】、細部は【Claude】と書いた所。
Claude Code へ：IMPL_REVIEW_2 の0-5（外から内へ、6段のヒアリング）は、このファイルで置き換える。`hearing_topics.json` は使わない（種の定義だけ `requirement_memory.json` と `survey.json` に移した）。
完成の判定は ACCEPTANCE.md の7（はじまり〜ヒアリング）に、下の「受け入れ基準」を足して行う。

## 1. 流れ【人間】
1. **来場者アンケート（選ぶだけ、20問ほど、2分）**：`data/content/survey.json`
2. **担当者の総括**：「ご記入ありがとうございます。〇〇なお家がご希望なのですね。〇〇と〇〇の両立は、検討してみます」
3. **追加の質問と補足（2〜4往復）**
4. **時間が来たら終わる**（初回打ち合わせは60分の枠。IMPL_REVIEW_2 の8の時計）
5. **帰り道に「これだけは！」を1〜2個だけ送る**（IMPL_REVIEW_2 の0-6）
6. 以上を統合した**「要望の全体の記憶」**を作り、見積・提案・その後のやり取りのすべてで使う：`data/content/requirement_memory.json`
7. 2社目は、同じアンケートの答えを使い回す（総括の切り口だけが会社で違う）

## 2. アンケートの画面【人間の案、Claudeが具体化】
- 1画面に1問。選ぶとすぐ次の問いへ（複数選べる問いだけ「つぎへ」）。各問に「こだわらない」
- 上に**「あと〇問」**と進み具合の線。段（外まわり → LDK → 水まわり・収納 → 個室 → そのほか → 雰囲気・お金）の見出しが切り替わるとき、軽く横にすべる
- 選択肢は大きな札（字22px以上）。押すと軽く沈んで色が付き、0.2秒で次へ。前の問いに戻れる「＜」
- 選んだ答えは、右の希望のボードに付箋として飛んでいく（v4の付箋のアニメーション）
- **ひとりプレイ**：AIのパートナーも同じ問いに答える（パートナーの人格から。答えは選択肢のidで）。プレイヤーが選んだあと、パートナーの答えが小さく出て、違えば「ふたりの意見が違う」の印（金の破線◆）。ふたりで遊ぶときは交互に答える
- 答えのうち、面積や予算の値（`engine`）はエンジンにそのまま渡す（Claudeは文章から読み取らない）。予算の2問は、希望の上限（IMPL_REVIEW_2 の1）になる
- 動きを減らす設定の人には、すべりと付箋の飛びを止める

## 3. 総括と追加の質問【人間の案、Claudeが具体化】
- 担当者の設定は `data/content/rep_harness.json`（共通の土台＋会社ごとの差分）。場面ごとに `phases.summary` → `phases.followUp`
- 総括：2〜3文。両立が難しそうな組み合わせ（例：LDK 24帖以上と総額4,500万円まで）があれば、1つだけ「検討してみます」と言う。どの組み合わせが難しいかはエンジンが判定し、プロンプトに渡す
- 追加の質問で聞くのは、①ふたりの意見が違う問い ②「こだわらない」が多い段 ③その会社の得意な所、だけ。アンケートに書いてあることは聞き直さない
- 細かい話は「承知しました。メモしておきますので、全体の計画の中で調整しましょう」で預かり、記憶の `deferred` に入れる
- 返事は `base.output` の形のJSON。`base.validator` をコードで当てる（2文まで、質問は1つまで、数字なし…）
- 時間の枠の残りが15分を切るか、2〜4往復が終わったら、担当者が「今日はこのあたりにしましょうか。次回までに、ラフなプランと概算をお持ちします」で区切る

## 4. 要望の全体の記憶【Claude】
- 形は `requirement_memory.json` の `shape`。要望1件ごとに、出どころ（アンケート／総括／追加の質問／帰り道のメッセージ／パートナー）と、**会社ごとに伝わったかどうか**を持つ
- 世界ごとに複製する。伝わったかどうかが世界で違うことが、のちの伝え漏れの出来事の種になり、画面には根拠として「アンケートに書いたのに」「帰り道に送ったのに」を出す
- 提案（Opus、IMPL_REVIEW_2 の17）、見積、担当者の会話、電気の打ち合わせ（ACCEPTANCE の4）、レポートは、すべてここを読む
- 同じ意味の要望は1件にまとめる（付箋の重複をなくす）

## 5. 受け入れ基準（ACCEPTANCE.md に足す）
- [ ] アンケートが20問前後、1画面1問、「あと〇問」が出て、2分ほどで終わる
- [ ] 担当者の最初の発言が「ご記入ありがとうございます」で始まる総括（2〜3文）
- [ ] 追加の質問は2〜4往復で、アンケートの聞き直しがない
- [ ] 担当者の発言が全部2文以内、質問は1回に1つ、数字がない
- [ ] 時間が来たら担当者が区切り、帰り道の1〜2個のあと、すぐ2社目へ
- [ ] 2社目は同じ答えを使い、総括の切り口が1社目と違う
- [ ] 付箋に重複がなく、出どころの印（アンケート／メッセージ…）がある
