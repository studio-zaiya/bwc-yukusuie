## インパクト (30%)
- 課題が、自分の仕事・暮らし・技術・趣味、または日本の具体的な現場から出発しているか
- テーマ1の場合：その世界に身を置いてきた人だからこそ見えた「足りないもの」を捉えているか
- テーマ2の場合：これまで届いていなかった具体的な人を想定し、その人を阻んでいた壁を取り除いているか
- 誰が、どんな場面で、どれくらい困っているかが具体的に描かれているか
- ハッカソン後も、誰がどんな場面で使い続けるかを具体的に言えるか

## デモ (25%)
- 「誰の、どんな課題を、どう解決するか」が冒頭で明確か
- 前提知識のない人でも、実際の操作の流れを通じて、使う人にとっての価値が分かるか
- 最後まで見たくなる、引き込まれる動画か

## Claudeの活用 (25%)
- Claude を創造的に使い、基本的な使い方を超え、Claude の新しい使い方や可能性を見せているか
- Claude Code を開発の中心に据え、それによって何が可能になったかを示せているか
- モデルや機能（Skills、サブエージェント、MCP、フックなど）を目的に応じて選び、使い分けているか

## 深さと実行力 (20%)
- 最初のアイデアにとどまらず、試行錯誤を重ねて磨き上げたか。その場しのぎではなく、課題にじっくり向き合った跡が見えるか
- 設計と実装がしっかりしていて、丁寧に作り込まれているか
- 困っている人が、安心してそのまま使える形に仕上がっているか

# テーマ（原文、人間が 18:27 にスクリーンショットで共有）
## テーマ1：あなたにしかない深さを。
仕事や職場、生まれ育った土地、学んできた技術、とことんのめり込んできた趣味。あなたが一番よく知っている世界を出発点にしてください。今回つくるものを実際に使うのは、その世界であなたの隣にいる仲間や、同じ地域で暮らす人たち、そしてこれからそこを引き継いでいく人たちです。そこに、いま何が足りていないのか。その中に身を置いてきた人だからこそ気づける「足りないもの」を見つけてください。
方向性の例：
- ベテランの仕事のやり方を、本人が現場にいるうちに、次の人が受け継げる形にする。
- 自分の経験や感覚を、自由な発想で、まだ誰も見たことのない形にする。
- 「そういうものだ」と誰もが諦めてきた日々の不便を、もう妥協しなくても良い便利なものにする。

## テーマ2：本来、誰にでも届くべきものを。
専門知識、費用、言語、手続き。さまざまな壁が、助けを受けられる人とそうでない人を分けています。多くの人を阻んできた壁を取り払い、一部の人にしか届いていないものを、届いていない人の手に。まずは壁の外側にいる具体的なひとりを思い浮かべてください。あるいは、高齢化や人手不足、災害への備えなど、日本社会がみんなで向き合う課題に、解決の一手を示してください。
方向性の一例：
- 専門家に頼れる人しか使えなかった手段を、必要な人なら誰でも使えるものにする。
- 読めずに諦められてきた書類や案内を、誰にでも分かる言葉にする。
- 人が減っていく地域でも、暮らしと備えを続けられる仕組みをつくる。
※ いずれも、暮らす地域の課題を Claude Code で解決する取り組みです。
